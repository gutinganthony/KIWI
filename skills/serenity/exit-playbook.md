## §0 為什麼一定要綁訊號（這條先讀）

`topics/other/2026-07-12-decision-quality-self-audit.md` 的 M1 結論：

> **綁訊號的賣出，執行率 100%；沒綁訊號的賣出，執行率 0%。**
（`topics/other/2026-07-12-decision-quality-self-audit.md:261`，此處為意譯非逐字引用）

實證就在自己的紀錄裡——宇瞻 8271 與 TEL 8035 都是依 WaveTrend cross 轉空訊號賣出的，
**有訊號、有執行**（`skills/serenity/watchlist.md:35`）。而所有「等 2027 再說」「看情況減」的計畫，
執行次數是零。

因此本手冊的鐵律：

1. **每一條出場條件都必須可以用「是／否」回答**，不能出現「若走弱」「視情況」「若基本面轉差」。
2. **日曆不是訊號。**「2027 分批出場」不是條件，是拖延。已於 §4 全部廢止並替換。
3. **觸發後有時限**：條件成立起 **7 個交易日內**必須執行或明文否決（否決要寫理由進本檔 §6 執行紀錄）。
   月度自檢第 8 題問的就是這個：「T1–T6 有無變燈？變燈後 30 天內有動作嗎？」——7 天是更嚴的自訂線。
4. **減碼幅度用「佔該部位的幾分之幾」表達**，不依賴絕對金額或組合權重（那些目前未記錄，見 §7）。

## §2 逐檔持倉的出場條件

持倉共 4 筆（`skills/serenity/watchlist.md:24-28`）。

### 2.1 DRAM（Roundhill Memory ETF）— **減碼順序第 1 位**

- **綁的燈**：T1（記憶體出場鐘）
- **為什麼排第一**：SK hynix 已拆除 LTA 價格上限、Samsung 無同等鎖價 →
  **本 ETF 無合約下檔保護**；MU 有 take-or-pay 地板。
  （`skills/serenity/watchlist.md:24`；判定依據 `topics/business/2026-07-26-memory-bear-market-multifactor-verdict.md`）

| 觸發條件（任一成立即動作） | 動作 |
|---|---|
| **DRAM 合約價 QoQ 轉負**（＝T1 正式響） | **減 1/2** |
| 4Q26 合約價預估**走平或轉負** | 減 1/3（T1 前置，先跑一步） |
| **DDR5／HBM 現貨跟進 DDR4 下跌**（DDR5 現貨連續 ≥2 週下跌） | 減 1/3（領先合約轉負 ~4.5 個月，`topics/business/2026-07-26-memory-bear-research/research_memory_bear_multifactor.md:562`） |
| Samsung／SK hynix **存貨連兩季回升** | 減 1/3 |
| **任一 hyperscaler capex 指引下修**（＝T6） | 減 1/2，並重判整個記憶體部位 |
| CXMT DDR5 擴產 + 進實體清單 | 減 1/3 |
| 量價背離（價漲量縮，週報宏觀燈判定） | 減 1/3 |

> **重複觸發累加**，但單月減碼上限為該部位的 2/3；要清倉必須是 T1 正式響 + 另一條同時成立。

### 2.2 MU Micron（~10% 部位）— **減碼順序第 2 位**

- **綁的燈**：T1，同一組條件，但**永遠在 DRAM ETF 之後執行**

| CXMT DDR5 良率達標（2026 底裁判） | 減 1/3 |
| T1 正式響（合約價 QoQ 轉負） | 減 1/2 |
