# PokerLab — 撲克作為決策訓練器

> **一句話**：這不是收入專案。撲克在 KIWI 裡的唯一身分是**不完全資訊決策的高頻模擬器**——成功指標寫在投資帳本上，不在牌桌上。
> **為什麼是這個定位**：完整評估見 `topics/other/2026-08-19-poker-as-decision-training-evaluation.md`（機會成本差一到兩個數量級、台灣境內線上真錢是刑法 §266 II 典型態樣、且與 E3 的 fit-and-proper 負相關）。**本檔只講怎麼做，不重述為什麼。**
> **標記**：🔧＝自訂門檻，無外部出處，Jake 可校準（`agents/LEARNINGS.md` 2026-07-27 規則）。

## §1 合規紅線（最短、最硬、先讀）

| 允許 | 禁止 |
|---|---|
| solver／trainer／play-money／手牌複盤（無對價） | **台灣境內以真錢在線上現金桌對局**（不論站點註冊地——行為地在台灣） |
| 台灣境內**積分制**錦標賽：籌碼僅作積分、獎金綁總名次、無即時兌現 | 現金直接買入／籌碼可即時兌現／單局勝負直接決定金額的任何賽事或牌局 |
| 合法轄區的現場賽事（出差／旅行順道，先確認當地與在職規範） | 以「協會」「俱樂部」為名但可換現金的場所 |

三條配套：
1. **在職身分優先**：任何載體在執行前，先確認不牴觸國泰的員工行為／兼職規範。說不清楚 → 不去。
2. **不留公開足跡**：實名帳號不發撲克內容（同 `skills/buildlab/SKILL.md` 的實名合規紅線邏輯）。摸魚記匿名軌若要寫，先過 `skills/viralcontent/SKILL.md` 的紅線。
3. **本檔所有法律敘述都是資料整理、不是法律意見。**
4. **律師諮詢的觸發點＝Gate 2**（2026-08-19 Jake 裁定）：真的要去打賽事之前才諮詢，不預先做。
   → 併進人生設計書 §五 第 5 項那次諮詢時一起問；**Gate 2 第 1 條未完成前不得報名任何賽事**。

> 給未來 session：Jake 若問「線上真錢站怎麼選／怎麼出金」，**不提供操作建議**，回到本節並改談三條合法載體。

## §2 三道閘門

### Gate 0 — 開跑資格（每次要推進本案都重驗，不是一次性）
1. 2026-08-31 基金架構定案**已交付並入庫**；
2. `AGENDA.md` 逾期任務 **≤2 項** 🔧（2026-08-19 基準：9 項。驗法：`python3 scripts/agenda_reminder.py --dry-run`，數 🔴 區條目）；
3. **EDINET API key 已放進 repo secret**（`topics/technology/mac-manual-homework.md` 最上方那項）。
   ⚠️ 第 3 條**刻意只綁一個具名項**，不綁「積欠總數」——該檔 2026-08-19 實測有 46 項未完成，設成總數門檻＝永遠紅燈＝等於沒設門檻。

三條全綠才准動。**未過即停**——不減量開跑、不「先看個影片」。
未過時 session 的動作：把三條現況念給 Jake 聽，再照他的決定執行。

### Gate 1 — 階段推進（P0→P1→P2→P3）
每階段有明文驗收門檻（見 `training-plan.md`）。**未達標不進下一階段，寧可留在原地多跑四週。**
理由：撲克是最容易「感覺變強、實際沒變」的領域，樣本量不夠時自我評估完全無效。

### Gate 2 — 錦標賽核准（一年最多一場 🔧）
四條全綠才報名：
1. 載體合法性逐條核對通過（§1）；
2. 已完成 P2 驗收；
3. buy-in ≤ **流動資產 0.2%** 🔧，且**視為已花掉的學費**，不進投資帳本、不算報酬率；
   ＋ **律師諮詢已完成**（§1 第 4 條：賽事前才問，但必須在報名前）；
4. 事前寫好〈這場我要驗證什麼〉一頁（不是「拿名次」，是三個具體決策假設）。

## §3 時間管理：**無上限，但全量測**

**2026-08-19 Jake 裁定：不設每週時數上限，自行把控。** 本節因此從「限制」改為「儀表板」——
系統的工作是**把數字擺在你面前**，不是替你踩煞車。

| 項目 | 規則 |
|---|---|
| 每週總時數 | **無上限**（Jake 自行把控） |
| 建議時段 | 週日晚，與 Serenity 週報同日 —— 兩件事共用一次「結算腦」 🔧（建議，非規定） |
| **必須記錄** | 每週撲克時數 vs KIWI 主線任務時數，寫進 `decision-log.md` 週結算 |

**保留的兩條（都不是時數上限，是後果條款）**：
1. **🚩 記號**：撲克時數 > 主線時數的那一週記一次 🚩 —— 只記錄，不阻止。
2. **否證條件 #1 仍有效**（§6）：連續 2 個月撲克時數 > 主線時數 ⇒ 整案終止。
   —— 這是結果導向的失效條款，不是事前配額。**你可以任何一週打很多；你不能連兩個月讓它蓋過主線。**

> 給未來 session：**不要**因為某一週時數高就出言提醒或勸阻——那是 Jake 明白收回的權限。
> 只在①週結算時如實報數字 ②否證條件真的觸發時 這兩個時點開口。

## §4 四階段（細節在 `training-plan.md`）

| 階段 | 週次 | 主題 | 驗收門檻 🔧 |
|---|---|---|---|
| **P0 地基** | 1–4 | 規則、賠率心算、preflop range、bankroll 數學 | pot odds／breakeven% 10 秒內心算 20 題全對；RFI/3-bet 表默寫 ≥90% |
| **P1 GTO 骨架** | 5–16 | 單一 spot 樹反覆 drill（BTN vs BB SRP → 3-bet pot → turn/river） | trainer 在**已練 spot** 上 EV loss <3 bb/100，連續 3 週 |
| **P2 實戰轉換** | 17–36 | 合法載體跑量、每 session 標 3 手複盤 | 累積 hand review ≥100 手，且其中 ≥20 手的錯誤歸類到同一個 leak 並被修掉 |
| **P3 賽事驗收** | 37–52 | 一場合法賽事＋事後複盤 | 賽前假設三條逐條回答；**名次不計入評分** |

## §5 回饋迴圈（本案唯一的產出義務）

**每月一條「poker→投資」轉譯**：把當月最大的一個撲克教訓，寫成一條**具體的、可執行的** KIWI 規則修改提案，落在 `skills/pokerlab/decision-log.md` 的月度區，並在 AGENDA 記一行。

已知的六條對應（優先按此順序挖）：

| 撲克能力 | 對應 KIWI 缺口 | 目標檔案 |
|---|---|---|
| bankroll / risk of ruin / Kelly | 無統一停損線、無單一部位上限 | `skills/serenity/exit-playbook.md` §7 缺口② |
| 結果 vs 決策品質分離 | 用結果評價決策 | 每月自檢第 9 條 |
| range 思維 | 判定落成點估計而非分布 | `skills/serenity/weekly-screen.md` |
| 對手建模 / exploit | 「對面是誰、他為什麼賣」 | `skills/socialarb/SKILL.md` |
| 變異數與樣本量 | n=1 翻轉判定 | 週報判定紀律 |
| tilt / 機械停損 | 死因 #2（零賣出） | `skills/serenity/exit-playbook.md` |

**連續 2 個月產不出轉譯 → 本案降級為純娛樂，時間盒砍半。** 產不出來就代表訓練沒有進到能被語言化的深度，繼續投入時間只是消耗。

## §6 否證條件（觸發即整案終止，不談判）🔧

1. 連續 2 個月，撲克時數 > KIWI 主線任務時數（**本案唯一的時間失效條款**——見 §3，無事前配額）；
2. 連續 2 個月，AGENDA 逾期項數量較開跑時**增加**；
3. 開跑滿 6 個月，trainer EV loss 無可測量改善；
4. 「在台灣線上玩真錢」的念頭被記錄 **≥2 次**（衝動不會消失，只能被計數）；
5. 任何一次違反 §1 紅線。

終止＝把本資料夾移進 `skills/buildlab/graveyard.md` 的同等位置並寫死因，不是「暫停觀察」。
