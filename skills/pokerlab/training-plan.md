## P0 — 地基（第 1–4 週）

**目標**：把「靠感覺」的部分全部換成算式。這四週不碰任何策略內容，只練算術與記憶。

### W1 — 結構與牌型
- 位置（UTG／HJ／CO／BTN／SB／BB）與其行動順序含義：**位置＝資訊，資訊＝EV**。
- 牌型排序、kicker、split pot 規則。
- **4-2 法則**：還有兩張牌要發 → outs × 4 ≈ equity%；只剩一張 → outs × 2。（例：flush draw 9 outs，flop 時 ≈36%、turn 時 ≈18%。）
- Drill：50 題「數 outs → 估 equity」，誤差 ≤3 個百分點。

### W2 — 賠率（本階段最重要的一週）
- **Pot odds**：要跟注 R 去贏 P（含對手下注）→ 需要的最低 equity ＝ `R / (P + R)`。
- 例：底池 100、對手下 50 → 你跟 50 去贏 150 → `50/200 = 25%`。
- **Implied odds** 與 **reverse implied odds**：後續街可再贏／可再輸多少。
- **MDF（最低防守頻率）**＝ `1 / (1 + s)`，s＝下注佔底池比例。下 1/2 pot → 對手需守 66.7%；下 pot → 50%。
- **GTO bluff 比例**＝ `s / (1 + 2s)`。下 1/3 → 20%；1/2 → 25%；2/3 → 28.6%；pot → 33.3%。
- **驗收 🔧**：20 題混合（pot odds／MDF／bluff 比例），**每題 10 秒內、全對**。未達標就再練一週，不進 W3。

### W3 — Preflop range（記憶週）
- 6-max RFI 開牌頻率近似區間 🔧（以 trainer 的實際解為準，這裡只是骨架）：UTG 15–18%、HJ 19–22%、CO 25–28%、BTN 42–48%、SB 35–45%。
- 3-bet／4-bet 的結構性理解：**linear（純強牌）vs polarized（強牌＋可棄的 bluff）** 取決於對手 range 與位置。
- Drill：每天默寫一張位置表，第 7 天閉卷。
- **驗收 🔧**：任一位置的 RFI 表默寫正確率 ≥90%。

### W4 — Bankroll 與變異數（會直接餵回投資的一週）
- 標準差：cash game 常見 σ ≈ 100 bb/100 🔧。N 手後的標準差 ＝ `σ × √(N/100)`。
- **算給自己看**：贏率 3 bb/100 的人打 10,000 手，期望 +300 bb，但一個標準差是 ±1,000 bb。**→ 訊號被雜訊淹沒三倍以上。要把 3 bb/100 從噪音裡分離，需要約 10 萬手。**
- **Kelly**：`f* = edge / odds`；實務用 1/4–1/2 Kelly。破產機率隨下注比例超線性上升。
- **這一週的真正產出不是撲克知識，是一份寫給投資帳本的備忘**：
  > 「我用 1 個季度、n=1 的財報翻轉一檔股票的判定，相當於用 500 手牌斷定自己的贏率。」
  寫進 `decision-log.md` 的月度轉譯，這就是第一條 poker→投資轉譯。

**P0 常見失敗**：跳過 W2 的驗收直接學策略（99% 的人）。**賠率不熟的人學 GTO 等於背答案。**

## P1 — GTO 骨架（第 5–16 週）

**目標**：不是「學會 GTO」，是**建立一個能被量測的基準線**，讓「我打得對不對」變成一個數字（EV loss），而不是一種感覺。
**工具**：雲端 trainer（GTO Wizard 等，本階段才訂閱；訂閱紀律見 `SKILL.md` §7）。
**方法**：每 2 週鎖定**一個** spot，drill ≥400 手。**不換主題，直到 EV loss 達標。**

| 週次 | 主題 | 重點 |
|---|---|---|
| 5–6 | BTN vs BB 單加注底池、flop | 33% range bet vs 75% polar 的分界：**牌面質地決定尺度，不是手牌強度** |
| 7–8 | BB 防守 vs 偷盲 | 牌面分類：乾燥／動態／成對／同花面；BB 的 range 優勢 vs 位置劣勢 |
| 9–10 | Turn 續攻與 equity realization | 哪些牌「值得繼續投資」——與投資組合的加碼決策同構 |
| 11–12 | River 兩極化 | 用 W2 的 bluff 比例反推：**尺度先決定，手牌後填入** |
| 13–14 | 3-bet 底池 | SPR（有效籌碼／底池）如何改寫一切；SPR 低＝承諾點提前 |
| 15–16 | 綜合＋leak 收斂 | 把前 10 週的錯誤歸類成 ≤5 個 leak，逐一重練 |

- **每 2 週產出**：一頁〈本主題我最大的偏差〉——寫「我原本怎麼想／解法怎麼做／差異的機制是什麼」。**只記結論不記機制的筆記無效。**
- **Gate 1 驗收 🔧**：已練 spot 的 trainer EV loss **<3 bb/100，連續 3 週**。未達標 → 留在 P1，不進 P2。

**P1 常見失敗**：
1. **主題跳躍**——每週換新 spot，看起來學很多，實際上每個都停在「知道但做不到」。
2. **把 GTO 當目標**——GTO 是基準線，不是打法。真實對手不平衡，exploit 才是錢所在（P2 處理）。
3. **用「感覺變強」取代 EV loss**——這正是 W4 那課的內容：沒有量測的進步不存在。

## P2 — 實戰轉換（第 17–36 週）

**目標**：把 drill 裡的正確決策搬到有壓力、有時間限制、資訊不完整的真實環境。
**載體**：僅限 `SKILL.md` §1 允許的三類。

### 每次 session 的固定程序
1. **開場 30 秒**：寫下今天要驗證的**一個**具體假設（例：「BB 防守 vs BTN 我棄太多」）。
2. **進行中**：任何猶豫 >5 秒的手，立刻標記（不當場想，標記就好）。
3. **結束**：挑 3 手寫進 `decision-log.md`，每手歸類到一個 leak 編號。
4. **機械停損 🔧**：單次 session 觸及以下任一條即離桌 —— ①時間到 90 分鐘 ②連續 3 手標記為「情緒驅動」 ③出現「想打回來」的念頭一次。

### 分段主題
| 週次 | 主題 |
|---|---|
| 17–20 | 執行一致性：drill 對、實戰錯的差距在哪（多半是時間壓力與 range 追蹤） |
| 21–24 | 對手建模：把對面分成 3 類（過度跟注／過度棄牌／被動），各寫一條偏離基準線的調整 |
| 25–28 | Exploit vs GTO 的取捨：**偏離基準線一定有代價，代價要算得出來** |
| 29–32 | Tilt 工程：記錄觸發器（bad beat／被詐唬成功／時間壓力），對每個觸發器寫一條機械規則 |
| 33–36 | Leak 收斂驗證：第 17 週列的 leak，有幾個真的消失了？ |

- **Gate 1 驗收 🔧**：累積手牌複盤 ≥100 手，且其中 ≥20 手歸類到**同一個 leak**、並有前後對照證明該 leak 頻率下降。
- **這一階段的投資轉譯最肥**：對手建模 → `skills/socialarb/`；tilt 觸發器 → `skills/serenity/exit-playbook.md` 的執行面。

**P2 常見失敗**：把「打了很多手」當作進度。**沒有標記與歸類的量＝零。**

## P3 — 賽事驗收（第 37–52 週）

**目標**：一場合法轄區的現場賽事，作為**驗收儀式**，不是收入事件。先過 `SKILL.md` §2 Gate 2 四條。

### 賽前（第 37–48 週）
- **MTT 專屬內容**（與 cash 差在哪）：
  - **籌碼深度分層**：深籌（>60bb）打 postflop／中籌（20–60bb）打 3-bet 與承諾點／短籌（<20bb）打 push-fold。
  - **Push/fold**：短籌時決策幾乎可查表，先把 10–15bb 的推牌區間背熟。
  - **ICM**：籌碼的**金錢價值非線性**——接近錢圈時，輸光的損失 > 翻倍的收益，所以正確打法比 chipEV 保守。**這是整份課表裡與投資最同構的一課：破產風險改寫最佳下注量。**
  - **bubble factor**：同一個 chipEV 中性的對局，在泡沫期是負 $EV。
- 賽程與體力：多日賽的決策品質隨時間衰減，把「幾點後不做大決策」寫成規則 🔧。
- **賽前一頁**：寫三條要驗證的決策假設（不准寫名次目標）。

### 賽中／賽後（第 49–52 週）
- 賽後 48 小時內完成複盤：三條假設逐條回答；**名次不計入評分**。
- **樣本量誠實條款**：MTT 的 ROI 要 **≥500 場**才有統計意義。一場的結果**不得**作為「我有沒有天賦／要不要加碼投入」的證據。任何以單場結果為由的擴張提案，直接引用本條駁回。

**P3 常見失敗**：打得好但賽果差 → 沮喪；打得爛但深入獎金圈 → 擴張投入。**兩者都是 W4 那一課沒學會。**
