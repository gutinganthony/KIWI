# PokerLab — 決策日誌（模板＋累積區）

> 本檔是 PokerLab 唯一的**產出義務**所在。牌打得好不好不記在這裡，**決策品質**與**投資轉譯**才記在這裡。
> 規則：`SKILL.md` §5。填寫時**先寫當下的想法，再寫事後的評估**——順序反了就失去訓練價值。

- 本週最大偏差（一句）：
- 🚩 記號：
```

```

## E. 月度轉譯（**本案唯一的成功指標**）

每月一條。**必須指名一個檔案與一個具體修改**，不接受「要更有紀律」這種寫法。

```
### YYYY-MM 轉譯 #__
- 撲克教訓（一句，含機制）：
- 對應的 KIWI 缺口：
- 目標檔案：skills/______  §__
- 具體修改提案（可直接執行的一句規則）：
- 狀態：提案／已寫入／已執行過一次
- 若被否決，理由：
```
