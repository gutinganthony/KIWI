# 核心 PCE 高於核心 CPI 的 798 個月

> **這份檔案的價值不在結論，在方法與否定。** 問題是「核心 PCE 高於核心 CPI 之後，股債怎麼走」。
> 答案是：**算得出來，但算出來的東西不能用**。本檔記錄為什麼。
> **資料層級**：FRED 官方序列（`CPILFESL`／`PCEPILFE`／`FEDFUNDS`／`USREC`／`UNRATE`）**自行計算**，非二手轉述。
> 取得方式見 §5——這條路徑對未來的 session 有用。

---

## 1. 先講結論

| 問題 | 答案 |
|---|---|
| 歷史上出現過嗎？ | **出現過很多次。** 1960-01～2026-07 共 798 個月，倒掛 **173 個月＝21.7%**——約每五個月就有一個月 |
| 有幾段？ | **34 段**，其中持續 ≥6 個月的有 **9 段** |
| 本輪算不算大？ | **算。+0.88pp（2026-07）是 1985 年以來最大**（此後各段峰值僅 0.70／0.69／0.55／0.27） |
| 有人研究過「倒掛之後資產怎麼走」嗎？ | **查無。** 擴大搜尋後確認：所有文獻都在解釋缺口「為何存在」與對 Fed 的意涵，**沒有一篇做事件研究** |
| 那自己算呢？ | 算得出來（見 §3），**但結果不穩健，不能當訊號用**（見 §4） |

**一句話**：這是一個**看起來像訊號、實際上是組成副產品**的數字。它告訴你通膨的形狀，不告訴你資產的方向。

| # | 期間 | 峰值缺口 | 備註 |
|---|---|---|---|
| 1 | 1960-03 ~ 1961-06 | — | |

| 3 | 1973-04 ~ 1974-05 | — | 第一次石油危機 |
| 4 | 1977-07 ~ 1978-03 | — | |
| 5 | **1982-09 ~ 1983-11** | **+2.00pp（全樣本最大）** | ⚠️ **不可當歷史教訓，見下** |
| 6 | 2003-03 ~ 2004-08 | 0.70pp | |
| 7 | 2005-06 ~ 2006-04 | 0.69pp | |
| 8 | 2010-01 ~ 2011-06 | 0.55pp | ⭐ **舊金山聯準會已歸因於住房權重** |
| 9 | **2025-11 ~ 迄今** | **+0.88pp（2026-07）** | 本輪 |

另有 2021-01~04 短段（峰值 0.27pp）。**2015 年沒有倒掛**（先前的猜測是錯的）。

### ⚠️ 1982–83 那段有結構性斷點，不能用

**BLS 於 1983-01 把 CPI 的自有住宅成本改為約當租金（OER）**，CPI-W 於 1985-01 跟進。這個改版**機械性壓低了 CPI 的住房項**，而 PCE 不受影響。
⇒ 1983 年前後的缺口**有一部分是定義變動造成的，不是經濟現象**。
📌 PIMCO 把分水嶺畫在 1985 年，很可能正是因為這件事。**引用「史上最大」時必須把 1983 前排除，否則是在比較兩把不同的尺。**

## 4. 🔴 為什麼上面那張表不能用

**四個理由，任何一個都足以推翻它：**

1. **n = 9。** 九個樣本的中位數，信賴區間寬到沒有意義。
2. **跨越三種貨幣制度**（布列敦森林、伏克爾、通膨目標制）**外加一次 CPI 定義改版**。這不是同一個母體。
3. **🔴 結果對「基準日怎麼定」極度敏感**：改用**倒掛開始**當基準日，S&P 12 個月中位數從 +2.8% **反轉成 +14.2%**——比無條件基準還高。**同一份資料，換個定義就換個結論 ⇒ 這是研究者自由度，不是發現。**
4. **沒有因果機制。** 缺口是三個編製效應（公式／權重／範圍）的加總，它不作用在任何資產的現金流或折現率上。

**⇒ 正確的用法：把它當成「通膨組成的溫度計」，不是「資產方向的訊號」。**
這也解釋了 §1 的「查無研究」——**不是沒人想到，是想到的人做完就發現不能發表。**

## 5. 🔴 本輪特有的資料瑕疵（最少人講，但最該知道）

**2025-10 美國政府關門期間，BLS 收不到租金調查，改用 carry-forward 處理（等同假設租金零成長）。**

- 住房佔核心 CPI **逾 40%** ⇒ 這個假設**機械性壓低核心 CPI**。
- 該假設會**錨定後續指數並延續**，據二手來源 **2026-06 才是修正後第一個完整月**。
- ⇒ **本輪倒掛的分母端（CPI）有一部分是統計假象，不全是經濟現象。**

⚠️ **可信度：二手**（bls.gov 被 egress proxy 擋，未取得原始技術說明）。**這一條在引用前必須自己去 BLS 原文確認**，已寫進 Mac 手動功課。

📌 **對其他分析的影響**：任何用 2025-11 ~ 2026-05 之間核心 CPI 讀數做的比較，都可能偏低。本 repo 目前引用的 **2026-08 讀數在修正期之後**，受影響程度較小，但 YoY 的基期仍落在受影響區間內。

## 6. 別人怎麼解釋這個缺口（三個分項，皆為他人論點）

| 分項 | 機制 | 出處 |
|---|---|---|
| **住房權重** | 住房佔核心 CPI 約 **34%**，佔核心 PCE 約 **16%** ⇒ 住房降溫時 CPI 掉得快得多 | PIMCO |
| **醫療範圍** | PCE 含**雇主與政府支付**的醫療，CPI 只含自付 | KBC |
| **金融服務** | 投資組合管理費隨**股市市值**計價，PCE 有、CPI 沒有 | 里奇蒙聯準會、PIMCO |

⭐ **最好的歷史對照：2010–11 那段，舊金山聯準會已明確歸因於住房權重**（《The Housing Drag on Core Inflation》）。
**與本輪同機制、方向相反**——當年是住房拖累核心通膨往下，現在是住房降溫讓 CPI 比 PCE 低。

## 7. 取得方式（對未來 session 有用）

**FRED 本體被 egress proxy 擋，但 GitHub raw 通。** 本輪經由 GitHub 上的 FRED 資料鏡像取得 `CPILFESL`（核心 CPI）與 `PCEPILFE`（核心 PCE）完整月序列，並自行計算年增率與缺口。

**驗收方式**：三個獨立計算互相交叉核對，**0 筆不符**；算出的 2026-07 缺口 **+0.88pp**、2026-01 **+0.59pp**，與 BEA／BLS 公布值完全吻合。
**成本**：只用 6 次 WebSearch（上限 18）。⇒ **需要長序列官方資料時，先試 GitHub raw 鏡像，不要先花額度在搜尋摘要上。**
