# 順手代購平台（工作代號：HANDCARRY，原 LTD）

> 前身推導：[Grabr 台灣複製可行性評估 v2](./2026-07-22-grabr-taiwan-feasibility.md)。
> **v2 定位（使用者 2026-08-03 修正）**：「Grabr 的亞洲版、Uber 版的順手代購、JPNJP 的進化版」。
> 主流需求＝**本來就要去目的地的人，順口幫本地有需求的人帶回東西**（日常品）。
> 稀有／排隊品**不是大宗需求**，是 edge case，由長期居住當地者或提高服務費解決。

---

# Part 0 — v2 重新定位造成的兩個結構性變化

## 0.1 v1 審查的核心矛盾，被這次定位「解掉」了

v1 雙聲部審查的最強發現是：

> 「**P2（低報酬的順便供給）與 P3（覆蓋率≒成功率）不可能同時為真。**」
> ——因為「能在發售日同時覆蓋 20 家店的人是專職黃牛，不是留學生順便」。

v2 放棄了「稀缺品搶購保證」這個承諾 → **沒有發售日同時性競賽 → 不需要 N 人覆蓋 → 順便供給與排單機制不再自相矛盾。** 這條矛盾正式失效，不是繞過，是命題被移除。

**代價**：唯一的 New 也跟著沒了。v1 的 New 是「用群眾覆蓋換成功率」；v2 拿掉稀缺承諾後，這個 New 不存在。必須重新數。

## 0.2 重數 Pincus：位置其實變好了，但賭注換了一張桌

| | v1（限定品保證） | v2（順手代購） |
|---|---|---|
| Proven | 集運／店到店／escrow／限定品需求 | 集運／店到店／escrow／**＋「順便帶東西」這個行為本身已在台灣大量存在**（IG 限動問朋友、FB 代買社團、蝦皮個人代購賣家）【常識層級，未量化 → 見 T4】 |
| Better | 成功率保證 vs 業者明說不保證 | **← 這一格現在是空的。全案存亡繫於此。** |
| New | 群眾覆蓋換成功率（已被審查證偽） | **把已存在的非正式行為平台化／可信化**（信任層＋金流層＋匹配層） |

**這是一個更好的 Pincus 位置，不是更差的。** 理由：v1 的 New 是一個「沒人做過、且經濟學上不成立」的行為；v2 的 New 是 **Airbnb／Uber 的標準型態——行為早就存在（沙發客、白牌車），創新的只有信任與金流基礎設施**。Pincus 最怕的「All new fails」在 v2 反而更遠。

**但賭注換了**：v1 賭的是「群眾能不能搶到貨」；v2 賭的是「**收費的陌生人媒合，能不能贏過免費的熟人媒合**」。

# Part 1 — v2 的三個硬問題（照重要性排序）

## 1.1 真正的對手換人了：不是集運，不是 JPNJP，是「我自己問朋友」

v1 把對手認成 Mercari／Buyee。v2 定位下，對手清單重排：

| 對手 | 它服務的情境 | 它的價格 |
|---|---|---|
| **「問朋友／等自己下次去」** | 幾乎所有日常品 | **NT$0，且對手風險為零** ← 真正的市占持有者 |
| 集運（比比昂 NT$100/kg 空運起、樂一番 5kg≈NT$975≈NT$195/kg、Buyandship NT$150/磅≈NT$330/kg）【已查證 2026-07-22】 | 日本**網路買得到**的東西 | 低且已商品化 |
| 蝦皮／FB 現有個人代購賣家 | 熱門日常品，已有現貨或預購 | 已含利潤，且是同一個「順便」模式 |
| JPNJP 等專營業者 | 實體店走訪代買 | 有人力成本，但可排程、可靠 |

**關鍵推論**：這四個對手中，**只有「問朋友」是免費且零信任成本的**，而它恰好覆蓋 v2 想服務的正中央（日常品、小件、金額不高）。Grabr 全球做不大的最可能原因就是這一條——不是需求不存在，是需求早就被免費的熟人網路吸收了。

→ **這不是否決，是把驗證題目定死**：你要贏的不是集運的運費，是**「問朋友」的三個結構性缺點**——(a) 朋友不一定這時候去、(b) 開口欠人情、(c) 不好意思麻煩對方繞路或墊錢。付費把人情債換成交易，這件事**有可能**值錢，而且是可以在一週內用真金測出來的。

## 1.2 Uber 的類比是錯的，Airbnb 才是對的——而且差別決定單位經濟

Uber 之所以成立，是因為 **司機已經在生產被賣的那個服務**（把車從 A 開到 B），乘客坐的是空座位，邊際成本接近零。

代購不是。旅客**沒有**在生產這個服務，他必須額外做四件事：
1. 走進一家**指定**的店（可能不在原路線上）
2. 買一個**指定**的 SKU（要對品項、拍照、留存證）
3. **扛回來**（佔行李重量與體積）
4. 落地後**交貨**（寄超商是另一趟事，約 NT$60）【已查證】

其中 (3) 是硬約束。所以正確的類比是 **Airbnb：你賣的是閒置的行李額度，不是空座位。**

**閒置行李額度的規模（上限推估，非預測）**：台灣 2025 出境約 1,894 萬人次、日本占 35.5% → 日均約 1.84 萬人次自日返台【出境數為已查證，日均為推算】。若每人回程有 2kg 閒置額度，即約 **36.8 噸/日** 的閒置跨境運能。資產確實巨大。

**但這個資產值多少錢，已經被集運訂死了**：買家對「把 1kg 從日本弄回台灣」的支付意願，錨在 **NT$100–330/kg**。所以：

> **決定性的單一數字**：一個旅客願意為「繞路 15 分鐘 ＋ 佔 0.5kg 行李 ＋ 墊 ¥1,500 ＋ 落地後寄超商」收多少錢？
> 若中位數報價 **> NT$250**，扣掉店到店 NT$60 與平台成本後，你在日常品上（客單 NT$300–1,500）沒有價差可分 → 模式在數學上死亡。
> 若 **< NT$150**，整案活著，而且很好看。

這個數字現在是空的。**它比留存率、比社團人數、比任何市場規模都重要**，而且問 20 個人就有答案（T3）。

## 1.3 「唾手可得」與「需要你」是反相關——但這次有四個真實的例外

反相關命題：**東西越好買 ⟺ 集運越可能也買得到 ⟺ 越不需要你。** v2 選擇日常品，等於選在這條反相關最不利的一端。

但這次認真找，**集運結構上做不到、而旅客做得到的缺口是真的存在**，共四類（依可信度排序）：

| # | 缺口 | 為什麼集運吃不到 | 可信度 |
|---|---|---|---|
| A | **日本沒有網路通路的實體現貨**：超市／便利商店／藥妝店現貨、期間限定口味、地方限定、麵包甜點、地方土產 | 集運（Tenso/ZenMarket/轉運倉）只能轉運「網路買得到並寄到日本地址」的東西；沒有商品頁就沒有起點 | **高**（結構性，非努力可克服） |
| B | **集運禁運／高風險品**：液體、噴霧、含酒精、含電池、部分食品 | 集運業者禁運清單長期存在；旅客託運在額度內可帶 | **高**（但要對照台灣輸入法規，見 1.4） |
| C | **速度**：旅客 3–5 天 vs 集運併倉＋空運＋清關約 7–14 天 | 集運的批次併倉是成本結構的必然 | 中（但日常品願為速度加價的幅度可能很小） |
| D | **免稅 10% 價差**：旅客持護照可辦日本消費稅免稅 | 轉運商在日本境內購買屬內需，付消費稅且不退 | **待查證且法律上脆弱**（見下） |

**D 的兩個未查證紅旗（不可當成優勢寫進商業計畫，除非先查掉）**：
- 日本免稅制度規定為「本人自用、攜帶出境」，**代他人購買是否符合免稅要件存疑**；且日本免稅制度近期有改制討論（改為出境時退稅、門檻調整）——**我的知識截止於 2026-05，此處必須查現行條文**。
- 台灣端：入境免稅額 NT$35,000、半年內入境逾 6 次不適用免稅額【已查證】；「代他人購買」在關務上屬非自用，規模化後正面撞上。

→ **A 是四者中唯一又大、又結構性、又不踩法規的缺口。** 若要收窄楔子，從 A 開始。

## 1.4 v2 新引入的三個風險（v1 沒有，因為 v1 賣的是高單價品）

| 風險 | 內容 |
|---|---|
| **客單價崩塌，固定成本吃掉一切** | v1 品類客單 NT$3,000–10,000，v1 審查算出的每單例外處理成本 NT$150–300 只占 3–5%；v2 日常品客單 NT$300–1,500，同一筆成本變成 **20–50%**。**v1 的單位經濟不能直接沿用，必須整份重算。** 直接推論：v2 必須**按趟聚合**（一個旅客一趟帶 5–10 單）才可能成立，單筆單送必死 |
| **行李額度是硬上限，供給極度碎片化** | 一個旅客一趟只能服務約 5–15kg，且只有一次。供給不是「留存率」問題而是**每趟一次性**——這代表 CAC 攤不掉，招募必須近乎零成本（社群自然增長），付費獲取供給端幾乎必然虧損 |
| **食品／藥品輸入紅線** | 日本零食是日常代購最大宗，但台灣**禁止輸入肉類製品**（含肉鬆、肉乾、含肉調理包／泡麵），罰則以萬元計【罰則金額未查證，列為必查】；藥品、含藥化妝品另有輸入數量管制。**一張明確的禁運品清單是上線前的法遵必要條件，不是 nice-to-have** |

# Part 2 — 建議的楔子收窄（一個具體提案）

綜合 1.1（要贏「問朋友」）、1.3A（唯一結構性缺口）、以及 v2「不要稀缺品」的定位，最一致的楔子是：

> ## 「**地方限定／實體通路現貨**」——朋友這次去不了那裡，集運沒有商品頁，JPNJP 的東京人力覆蓋不到。

理由對齊三個約束：
- **對「問朋友」有優勢**：你朋友這次去東京，但你要的是北海道／沖繩／名古屋的限定品——**朋友解不了地理錯配，群眾可以**。這是「順便」邏輯唯一能真正打贏熟人網路的地方。
- **對集運有優勢**：地方限定＝實體通路專屬，通常沒有可轉運的商品頁（缺口 A）。
- **對 JPNJP 有優勢**：專營業者的自有人力集中在東京大阪，**廣度是群眾的天然強項**，而且廣度不需要同時性——完全不觸發 v1 的 P2/P3 矛盾。
- **且不是稀缺品**：地域限定是量產品，只是通路受限。沒有抽選、沒有排隊、沒有黃牛、沒有懸賞多派的 N× 成本。

**這個楔子的 Better 一句話**：「**你在日本任何一個角落的一雙手**」——賣的是覆蓋廣度，不是搶購能力。這句話 v1 講不出來（因為被稀缺品綁死），v2 講得出來。

**同時要誠實的一點**：地方限定品客單價低（NT$200–800/件），單筆必虧，**必須靠「一趟多單」與「多買家併同一趟」才成立**——這把 D 級設計題從「排單」變成「**行程配對與併單**」，是完全不同的工程與營運題目。

# Part 3 — v2 驗證清單（全部是紙上或問人，總計 <2 週、近乎零成本）

| # | 測試 | 做法 | 判準 |
|---|---|---|---|
| **T1** | **價差測試（Better 的唯一考題）** | 取 20 個真實日常品，並排三價：(a) 集運總成本＝日本網購價＋NT$100–330/kg＋店到店；(b) 蝦皮／FB 現有代購報價；(c) 你的預估報價 | **(c) 至少要在 8/20 品項上低於 min(a,b)，或提供 a 與 b 都做不到的東西。**達不到 → Better 不成立，停 |
| **T2** | **通路可得性測試（TAM 的真實形狀）** | 同 20 品，逐項查「日本網路是否買得到」「網路價是否 >1.5× 店頭價」 | 「網路買不到／顯著更貴」比例 **<30% → 整案退回運費價格戰**，沒有生意 |
| **T3** | **供給端真實報價（決定性數字，見 1.2）** | 問 20 個近期要去日本的人：「幫陌生人買 ¥1,500 的東西、繞路 15 分鐘、佔 0.5kg 行李、回台寄超商，你收多少？」**先問報價，不要先講你的服務** | 中位數 **>NT$250 → 數學上無利可圖**；<NT$150 → 綠燈 |
| **T4** | **熟人替代測試（真對手的市占）** | 問 20 個買家「上次想要日本東西時，實際怎麼做的」（Mom Test：問過去行為，不問意願） | 「問朋友／自己等下次去」占比即為真對手市占；若 >70% 且受訪者說不出摩擦 → 你在跟免費且無風險的東西競爭 |
| **T5** | **免稅與關務可行性（法遵）** | 查日本現行免稅要件是否允許代他人購買＋近期改制；查台灣「非自用」認定與逾 6 次規則的實務 | 若代購不符免稅 → 缺口 D 從商業計畫刪除 |
| **T6** | **禁運品紅線清單（法遵，上線前必要條件）** | 列出台灣禁止／管制輸入的品項（肉類製品、藥品、含藥化妝品、動植物），與日本出境限制 | 產出一張可直接掛在下單頁的黑名單 |

**建議順序**：**T1＋T2 先做（一天，純桌面）**。這兩題若過不了，T3–T6 全部不用做。
T2 若通過，再做 T3（半天，問人）——**T3 的中位數報價是本案最便宜的決定性數字**。

# Part 4 — v1 審查發現在 v2 下的存活表

| v1 發現 | v2 狀態 |
|---|---|
| P2 與 P3 結構性互斥 | **失效**（v2 移除稀缺承諾，矛盾消失） |
| 懸賞多派 N× 成本（D1） | **失效**（無同時性競賽） |
| 保證定價公式（D6）、保證分母與拒單權（D5） | **失效**（v2 不賣成功率保證） |
| 砍除球鞋抽選／藥妝限定包裝（C） | **失效／部分轉化**：抽選已不在範圍；藥妝的輸入管制轉入 T6 |
| 相關性風險（同發售日炸單） | **大幅減弱**（無發售日） |
| 人工兜底的假成功（F） | **減弱**（無保證即無兜底誘因），但「營運自己去買」仍需在指標上分離 |
| **在留資格違法風險** | **存活但減輕**：v2 以旅客為主力，留學生只在 edge case；仍不得以招募留學生為業 |
| **資金池＝代收代付法遵紅線** | **完全存活**，且更急迫（日常品筆數多、金額小、筆數即風險） |
| **防繞過（雙方私下 LINE）** | **惡化**：日常品是重複購買，繞過誘因遠高於一次性限定品 |
| **結案狀態機（D2：完售／拒賣／限購）** | **存活**（改為缺貨／停產／改版／限購） |
| **虛擬卡實地測試（V3／D3）** | **存活且更關鍵**：v2 的通路是超市／便利商店／藥妝店，小額支付受理率是全案基礎 |
| **例外處理成本（D10）** | **存活且惡化**：見 1.4，占客單比例上升 5–10 倍 |
| **可複製性（JPNJP 3–6 個月）** | **惡化**：順手代購比「保證」更容易複製，護城河只剩網路效應 |
| **10x 重框：真正複利的是庫存與命中率資料集（E）** | **存活且更強**：v2 的資料變成「**哪個城市／哪家通路／現在有沒有貨**」，而地方限定楔子天然在蒐集這份資料 |
| **替代路徑：自營買手起手／B2B 批發覆蓋率／純承保層（D）** | **前兩條存活**：自營買手仍是取得資料的最快路徑；B2B（賣覆蓋率給既有代購業者）在 v2 下更成立，因為賣的就是廣度 |

# Part 5 — v1 原文（歷史記錄，勿當現行方案）

## v1-1. 一句話與 Job to be done

**買家的 job**：我要一件只有日本實體店買得到的東西（園區限定／店頭限定／抽選限量），而且我要**確定拿得到**。
**產品承諾**：不是「幫你帶」，是「**成功率 X%，沒買到全額退**」。

## v1-2. 模式結構

| 層 | 設計 | 性質 |
|---|---|---|
| 需求端 | 台灣買家下單指定商品/店鋪/期限 | — |
| 採買 | 在日當地生活者順便繞進店家；旅客為備援 | 唯一的 New |
| 墊資 | 平台預撥／虛擬卡 | Proven |
| 運輸 | 集運為主 | Proven |
| 最後一哩 | 超商店到店（約 NT$60） | Proven |
| 金流擔保 | escrow | Proven |
| 收費 | 服務費 %＋繞路/加急加價 | 待驗證 |

## v1 autoplan 審查產出（雙聲部 opus×2）

**A. 核心發現**
| 聲部 | 發現 |
|---|---|
| CEO | 群眾能解**搜尋問題**（不值錢）；**配給問題**（供<需、抽選、一人一件）群眾解不了——而客戶願付溢價的正是配給問題 |
| 營運 | 限定品稀缺來自**開店前排隊**不是路過；能在發售日同時覆蓋 20 家店的是**專職黃牛，不是留學生順便** |

→ **P2 與 P3 不可能同時為真。**

**B. 成本優勢只在你不需要它的時候存在**：對手是 Mercari／駿河屋／ヤフオク＋Buyee，多數限定品 24–72 小時出現在二手、溢價 1.3–2 倍；你的成本 25–40% 理論上有空間，但「懸賞多派」把成本從 1× 變 N×，直接衝破二手溢價區間。→ 簡單品項你便宜但客戶不需要你；困難品項客戶需要你但你比 Mercari 貴。

**C. 必須砍掉的品類**：球鞋抽選／本人受取抽選（在留卡＋日本門號＋實體會員，中獎品法律上屬採買者，多數明文禁止代購轉售）；藥妝店限定包裝（含藥化妝品輸入數量管制）。

**D. 三個未評估的替代路徑**：自營／簽約買手起手（取得承保資料的唯一途徑）／B2B 批發覆蓋率給既有需求方（零消費者 CAC）／純承保層。

**E. 10x 重框**：會複利的資產不是採買勞動力，是「哪家店 × 哪個時點 × 哪個 SKU 真的有貨」的即時庫存與命中率資料集。

**F. 六個月最可能的死法**：「指標好看的人工兜底」——群眾接不下的單，營運默默去 Mercari 補貨履約，成功率 95% 但唯一的 New 已死。解法：北極星＝未經人工兜底的群眾首次命中率。

**v1 驗證 V1–V5**：二手滲漏測試／P3 殺手測試（單人一店 vs 20 店命中率差 <15pp 即 New 死亡）／虛擬卡實刷 20 次／招募 30 人跑 4 週／需求量化（需 /browse 進社團）。

**v1 留意 8 條**：人工兜底假成功／在留資格違法／資金池代收代付／雙向逆選擇／供給端道德風險／防繞過／相關性風險／可複製性。

**v1 設計 D1–D10**：懸賞多派／結案狀態機／墊資控制（虛擬卡限單店單次金額當日＋JAN＋GPS＋雙對帳＋保證金）／責任分割線（交付集運前照片為界）／保證分母與拒單權／保證定價公式 ≥(1−成功率)×N×出勤費／信用分三軸／冷啟動鎖三商圈／發售日曝險上限／每單預留 NT$150–300 例外成本。
