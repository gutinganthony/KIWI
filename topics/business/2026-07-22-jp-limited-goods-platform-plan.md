# 日本限定品群眾採買平台（工作代號：LTD）

> 前身推導：[Grabr 台灣複製可行性評估 v2](./2026-07-22-grabr-taiwan-feasibility.md)。定位一句話：**「優化版 JPNJP × Grabr」——用群眾覆蓋率換成功率的日本實體店限定品代買服務。**

## 1. 一句話與 Job to be done

**買家的 job**：我要一件只有日本實體店買得到的東西（園區限定／店頭限定／抽選限量），而且我要**確定拿得到**。

**產品承諾**：不是「幫你帶」，是「**成功率 X%，沒買到全額退**」。

## 2. 模式結構

| 層 | 設計 | 性質 |
|---|---|---|
| 需求端 | 台灣買家下單指定商品/店鋪/期限 | — |
| **採買** | **在日當地生活者**（留學生／工作者／長住台人）順便繞進店家；旅客為備援 | **唯一的 New** |
| 墊資 | 平台預撥／虛擬卡，採買者不出自己的錢 | Proven（fintech 既有方案） |
| 運輸 | 集運為主（Buyandship NT$150/磅、比比昂 NT$100/kg 起） | Proven、已商品化 |
| 最後一哩 | 超商店到店（約 NT$60，全台密度世界級） | Proven、台灣結構優勢 |
| 金流擔保 | escrow，確認收貨才撥款 | Proven（蝦皮已教育市場） |
| 收費 | 服務費 %（高單價品類）＋繞路/加急加價 | 待驗證 |

## 3. Pincus 計數

- **Proven**：集運（實價已知）／超商店到店／escrow／需求（JPNJP、Japan Easy Buy、萬屋商行、跨買 TOKUKAI 等多家長期專營已證明）
- **Better（10/10 測試）**：成功率保證 vs 現有業者明說的「不能 100% 保證搶到」
- **New（只有一個）**：**用群眾覆蓋換成功率**——一家公司只能派一人去一店，群眾可在發售日同時覆蓋 20 家店；**覆蓋率 ≒ 成功率**

## 4. 目標品類（依楔子鎖定高單價、小體積、實體店專屬）

動漫周邊限定／迪士尼・USJ 園區限定／球鞋抽選／藥妝店限定包裝。
**排除**：網路買得到的一般商品（集運與官方跨境已便宜解決）、重物液體（旅客備援路徑扛不動、集運又貴）。

## 5. 明定前提（審查對象，每一條都可能錯）

| # | 前提 | 若為假 |
|---|---|---|
| P1 | 「買不到得夠可靠」是真實且付得起錢的痛點（非「便宜一點」） | 產品承諾失效，退回價格戰 |
| P2 | 在日當地生活者的供給可被招募且留存（順便繞路的報酬足夠） | 唯一的 New 不成立 |
| P3 | 群眾覆蓋真的能把成功率拉高到明顯優於單一業者 | 差異化消失 |
| P4 | 目標品類單價足以吸收繞路費地板（NT$500–1,500） | 單位經濟不成立 |
| P5 | 抽選/限量代買在商家條款與法規上可行 | 最核心品類被砍 |
| P6 | 匹配密度（每商圈活躍採買者數）足以支撐承諾 | 承諾跳票、賠付爆炸 |
| P7 | 賠付成本（沒買到全額退）可控且可定價 | 保證變成無底洞 |

## 6. 已知數據（查證過）

- 日→台集運：Buyandship NT$150/磅（0.2 磅低消）｜比比昂 NT$100/kg 空運起｜樂一番 5kg≈NT$975
- 超商店到店約 NT$60
- 台灣出境 2025 約 1,894 萬人次、日本占 35.5%（每日約 1.84 萬人次）——**旅客為備援路徑的底氣，非主力**
- 現有業者覆蓋邊界：純集運（Tenso／ZenMarket／Buyandship 自助）結構上做不到實體店限定品；JPNJP 已提供實體店走訪代買與付費線上抽選，但**不保證成功**
- 法規：入境免稅額 NT$35,000／半年逾 6 次免稅不適用／月銷 >NT$8 萬須稅籍登記（散客供給可避開，規模化須正面處理）

## 7. 最大缺口（未查證）

需求的**量化規模**（社團人數、成交溢價、月成交量）——搜尋額度內查無，需 /browse 直接進社團清點。

## 8. NOT in scope（初版）

自建物流／自建倉儲／一般商品代購／非日本市場／App（先用表單與人工）。

# autoplan 審查產出（雙聲部 opus×2，[subagent-only]；Codex 不在此環境）

## A. 核心發現：模式有一個結構性矛盾（兩聲部獨立收斂）

| 聲部 | 各自的發現 |
|---|---|
| CEO | 群眾能解**搜尋問題**（貨在某處不知在哪）——但免費的在庫檢索也能解，不值錢；**配給問題**（供<需、抽選、一人一件）群眾解不了——而客戶願意付溢價的正是配給問題 |
| 營運 | 限定品的稀缺來自**開店前排隊**，不是路過。能在發售日同時覆蓋 20 家店的人是**專職黃牛，不是留學生順便** |

**合起來：P2（低報酬的順便供給）與 P3（覆蓋率≒成功率）不可能同時為真。** 這不是執行問題，是命題自相矛盾。

## B. 第二個致命交互：成本優勢只在你不需要它的時候存在

- 真正的對手是 **Mercari／駿河屋／ヤフオク ＋ Buyee**：多數限定品發售後 **24–72 小時**出現在二手市場，溢價 **1.3–2 倍**
- 你的成本結構約 **25–40%**（繞路費＋集運＋店到店＋賠付準備）——**低於**二手溢價中位數，理論上有空間
- **但**：搶得到難貨需要「懸賞多派」（一單同時派 N 人、先成功者得全額、其餘領出勤費），成本從 1× 變 **N×** → 直接衝破二手溢價區間

→ **簡單的品項你比 Mercari 便宜，但客戶不需要你（集運就解決）；困難的品項客戶需要你，但你比 Mercari 貴。**

## C. 必須砍掉的品類（法律/技術不可行，非選擇題）

| 品類 | 原因 |
|---|---|
| **球鞋抽選／本人受取抽選** | 需在留卡＋日本門號＋實體會員；帳號與中獎品法律上屬採買者；多數明文禁止代購轉售；平台執行力為零 |
| **藥妝店限定包裝** | 含藥化妝品輸入數量管制，化整為零報關踩線 |

## D. 三個未被評估的替代路徑（兩聲部都點名）

1. **自營／簽約買手起手**（10 名東京・大阪兼職）：可排程、無冷啟動、無逆選擇，**且是取得承保資料的唯一途徑**。群眾應是規模化後的成本優化，不是起手式。
2. **B2B 批發覆蓋率**給既有需求方（JPNJP／萬屋／蝦皮賣家）：他們有需求你沒有、你有覆蓋他們沒有，**零消費者 CAC**，直接變現唯一的 New。（賣 SaaS 工具是弱版，賣履約產能是強版。）
3. **純承保層**：別人執行，你為成功率定價收費——資產最輕，但需要你現在沒有的命中率資料庫。

## E. 10x 重框（CEO 聲部，本次最有價值的一句）

會複利的資產不是採買勞動力，是「**哪家店 × 哪個時點 × 哪個 SKU 真的有貨**」的即時庫存與命中率資料集。以資料為核心 → 能承保、能定價、能賣給所有代購業者；以勞動力為核心 → 只是低毛利跨境派遣。

## F. 六個月最可能的死法

**「指標好看的人工兜底」**：群眾接不下的單，營運默默去 Mercari／駿河屋補貨履約 → 成功率 95%、客戶滿意、GMV 成長，但唯一的 New 已死且數字看不出來，毛利在最出名的那批單上是負的。
**解法**：北極星＝**未經人工兜底的群眾首次命中率**，與整體成功率分開揭露；跌破門檻即視為模式證偽。

# 關鍵節點清單（使用者要的三類）

## 🔬 驗證（go/no-go 實驗，全部可在 2–3 週內完成，不需建任何系統）

| # | 測試 | 判準 |
|---|---|---|
| V1 | **二手滲漏測試**：取 20 個限定品，量測 72 小時內出現在 Mercari／駿河屋的比例與溢價 | 滲漏率高且溢價 <1.4x → 楔子不存在，停 |
| V2 | **P3 殺手測試**：取 30 個真實歷史限定品，回測「單人一店 vs 20 店同時」的命中率差 | **差距 <15 個百分點 → 唯一的 New 死亡** |
| V3 | **虛擬卡實刷**：帶卡到舞浜／池袋／秋葉原實刷 20 次（園區攤位、小店、藥妝） | 拒受率高 → 墊資機制不成立（計畫把它列為 Proven 是錯的） |
| V4 | **供給端可行性**：招募 30 人跑 4 週真實派單 | 48h 接單率與第 4 週留存；留存崩 → P2 死 |
| V5 | **需求量化**（最大缺口）：社團人數、月成交量、成交溢價 | 需 /browse 直接進社團清點 |

## ⚠️ 留意（會慢慢殺死你的東西）

1. **人工兜底的假成功**（見 F）——北極星指標必須拆兩層
2. **在留資格違法風險**：日本「留学」在留資格需資格外活動許可、每週上限 28 小時，以代購為業恐違反在留資格；**招募留學生等於誘使其違法，出事反噬平台**
3. **資金池＝代收代付**：自建 escrow 在台涉第三方支付／電支法遵，是紅線 → 初版一律掛靠既有金流商履約保證專戶
4. **雙向逆選擇**：買家只給難單、採買者只挑好單
5. **供給端道德風險**：東西真值錢時，採買者自己上 Mercari 比履約划算
6. **防繞過**：一次成交後雙方私下 LINE，平台被跳過
7. **相關性風險**：同一發售日會同時炸掉數百張單
8. **可複製性**：JPNJP 複製一個「保證」SKU 約 3–6 個月，且已有買家/品牌/日本法人/現成買手

## 🛠 設計（上線前必須存在的機制）

| # | 機制 | 要點 |
|---|---|---|
| D1 | **排單：懸賞多派** | 一單派 N 人、先成功者全額、其餘出勤費——**服務費模型必須反映 N× 成本**（現版完全沒反映） |
| D2 | **結案狀態機** | 完售／拒賣／限購＝「非違約失敗」：買家全額退、採買者領出勤費（平台自吃）、須上傳店頭照片存證。**這三者才是最高頻結局** |
| D3 | **墊資控制** | 虛擬卡限單店＋單次＋金額上限＋當日有效；現場掃 JAN 條碼＋店家 GPS 才放行；卡片紀錄與交付照片雙對帳才解鎖報酬；收採買者保證金 |
| D4 | **責任分割線** | 「交付集運前照片」為界：之前歸採買者、之後歸物流；下單必填 JAN/型號/官方圖，條碼比對失敗不撥款 |
| D5 | **保證的分母與拒單權** | 分母＝平台**接單且標記為保證級**的訂單；平台保留拒單與加價權（承保方沒有拒絕權就不是承保） |
| D6 | **保證定價公式** | 保證溢價 ≥ **(1−預估成功率) × N × 出勤費**，按難度分級，非全站統一 X%。賠付＝退款＋平台券，**不賠現金/雙倍** |
| D7 | **信用分三軸** | 成功率／接單後放鴿率／證據合規率 → tier 決定可接單金額與能否接保證級單；低 tier 看不到高價好單 |
| D8 | **冷啟動** | 鎖 3 個商圈（池袋／秋葉原／舞浜）；供給端保底出勤費單邊補貼；需求端預約制，湊滿同商圈同日訂單才派人 |
| D9 | **曝險上限** | 每個發售日設訂單上限 |
| D10 | **例外處理成本** | 單位經濟預留每單 NT$150–300（跨境＋限定品＋保證＝每單皆是例外）；另有日圓鎖匯風險與「平台被迫當真偽鑑定方」 |
