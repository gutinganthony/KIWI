# 順手代購 T1／T2 驗證與雙邊 User Journey

> 對應計畫：[順手代購平台 v2](./2026-07-22-jp-limited-goods-platform-plan.md) 的 T1（價差測試）與 T2（通路可得性測試）。
> **查證條件（先讀）**：本次環境的網路政策封鎖所有外部站台（WebFetch / headless browser / curl 全部 403 或 tunnel failed），**只有 WebSearch 可用**。因此本文價格為搜尋摘要層級，**未逐項核實商品頁**。原訂「20 品 × 三價並排」只做到 **7 組可比價格對**。判定標示為 PARTIAL 者即為此故。
> **匯率假設**：NT$0.21/¥，由本文多筆實例反推（¥2,780≈NT$592、¥980≈NT$196–205、¥280≈NT$58），**非官方牌價**，實作時須以當日匯率為準。

---

## 1. 台灣人最常請朋友代買什麼（調查結果）

依搜尋所得，可分五群。**「被託帶」與「旅遊必買清單」不是同一件事**——必買清單是自己買，託帶是別人開口，後者集中在重複購買、低決策成本的日用品。

| 群 | 代表品項 | 為什麼被託 |
|---|---|---|
| **A. 成藥／保健** | EVE 止痛藥、龍角散、合利他命、大正漢方胃腸藥、小林退熱貼、休足時間 | 台灣通路有但貴／劑型不同；重複購買 |
| **B. 保養與防曬** | 安耐曬、ALLIE 防曬、面膜、化妝水、卸妝油 | **台日價差最大的一群**（見 §2） |
| **C. 零食伴手禮** | 地域限定 KitKat、白色戀人、ORIHIRO 蒟蒻果凍、便利商店期間限定、超市限定 | 情感需求＋「台灣買不到」 |
| **D. 角色周邊／抽賞** | 吉伊卡哇、三麗鷗、一番賞、迪士尼/USJ 園區限定、Loft 限定文具 | 有真實溢價（見 §2） |
| **E. 家電與雜貨** | 象印保溫瓶、Vitantonio 鬆餅機、美容儀（YA-MAN）、HARIO 手沖器具、Snow Peak 日本限定色 | 單價高、價差大，但體積重量是硬傷 |

一個容易被忽略的實例：PTT 討論串裡「代買過最鬧的東西」提到**衛生棉條**因台日價差大而被大量託買——這類「台灣有賣但貴很多的日用消耗品」才是託帶的真正大宗，不是伴手禮。

## 2. T1 — 價差測試（判準：至少 8/20 品項低於 min(集運, 現有代購)）

### 2.1 取得到的可比價格對（7 組）

| 品項 | 日本店頭價 | 台灣現有管道到手價 | 價差 | 對你的意義 |
|---|---|---|---|---|
| EVE A錠 60錠 | ¥980 特價（定價 ¥1,760）≈NT$206 | 日藥直送平台 **NT$196–240** | **≈0 或負** | ❌ |
| 龍角散喉糖 88g | 希望售價 ¥280（實售更低）≈NT$58 | 屈臣氏 **NT$70** | **+NT$12** | ❌ |
| 龍角散喉糖 40g/10粒 | — | 屈臣氏蝦皮商城 **NT$59** | — | ❌（已是通路常備品） |
| 安耐曬金鑽高效防曬 | ¥2,780 ≈NT$592 | 台灣「不算便宜」（未量化） | 有差未量化 | ⚠️ |
| ALLIE 防曬 | — | 日本價約台灣的 **1/3–1/2** | **2–3×** | ✅ 但見 §2.3 |
| 一番賞 單抽 | ¥600–800 ≈NT$160–220 | 台灣代抽 **NT$350–380**（黑店 400–450） | **1.7–2.1×** | ✅ 但見 §2.3 |
| 一番賞 拆賞單品 | 原價 | 台灣售價高 **2–4×** | 2–4× | ✅ 但見 §2.3 |

### 2.2 你要付的成本（同期查證）

- **現有代購服務費行情**：商品金額的 **5–20%**（小眾特殊品更高），或每筆固定 **NT$100–250**。分級費率實例：¥0–5,000 加 25%、¥5,001–10,000 加 22%、¥10,001–20,000 加 20%、¥20,001–30,000 加 18%、¥30,001+ 加 15%，最低手續費 ¥300。
- **集運**（2026-07-22 查證）：比比昂 NT$100/kg 空運起｜樂一番 5kg≈NT$975（≈NT$195/kg）｜Buyandship NT$150/磅（≈NT$330/kg）
- **最後一哩**：超商店到店約 NT$60

### 2.3 T1 判定：**不通過（PARTIAL — 樣本 7/20）**

7 組裡只有 2 類贏，而且兩類都撞牆：

**「價差剪刀」——這是本次最重要的發現：**

> **價差大的品類（防曬、化妝水、卸妝油）＝液體＝撞上日本出境「液體狀／噴霧狀化妝品與醫藥品」單件 ≤0.5L/0.5kg、合計 ≤2L/2kg 的上限（國土交通省規定）。**
> **沒有這個上限的品類（喉糖、錠劑成藥、零食）＝價差已被台灣官方通路與日藥直送平台壓到 NT$12 以內。**

而且 2kg 上限是**與旅客自己買的合併計算**，不是額外配額。一個自己也要買防曬的旅客，可用額度接近 0。彩妝（粉底、唇彩、護唇膏）不在此限，是唯一的縫隙。

**另外兩個直接的反證：**

1. **「藥品集運做不到」是錯的假設。** 市面上已有專營日藥跨境直送平台（EBISU 恵比壽日藥直送、SUGI 跨境購物、樂樂JAPAN 一口價代購）。集運本身對 OTC 醫藥品採「單件 ≤0.5L/0.5kg、總量 ≤2L/2kg」而非全面禁運；非噴霧型保養品（乳液/面霜/精華液）可正常集運。**A 群與 B 群大部分已被覆蓋。**
2. **唯一有真溢價（1.7–4×）的品類是一番賞／角色周邊，也就是你上一輪決定不做的稀缺品**；而且官方「一番賞Online」已上線，正在把這個利基線上化。

**結論一句話**：資料指向的唯一賺得到錢的品類，正好是你剛決定不做的那一類；你決定要做的那一類，價差已經被官方通路吃光了。

## 3. T2 — 通路可得性測試（判準：「網路買不到／網路顯著更貴」比例 ≥30%）

### 3.1 明確**網路買不到**（結構性缺口，集運沒有起點）

- **地域限定**：北海道 Seicomart 限定飲料零食、長野 DELiCiA 的縣產品——「網路通常買不到這些地域或店舖限定的商品」
- **便利商店自有品牌與期間限定**：LAWSON×GODIVA 聯名甜點等，一波一波、期間限定
- **店舖限定／園區限定**：Loft 澀谷店限定文具、迪士尼/USJ 園區獨家商品
- **季節與口味限定**：地域限定 KitKat 等

### 3.2 明確**網路買得到且已被覆蓋**

EVE、龍角散、蒸氣眼罩、退熱貼、白色戀人、東京香蕉、非噴霧型保養品——全部可透過集運或日藥直送平台取得。

### 3.3 集運／入境的硬限制（做 T6 黑名單用，已可直接落地）

| 類別 | 規則 | 來源 |
|---|---|---|
| 肉品 | 生肉、熟肉、加工肉製品**一律禁止**輸入台灣；含肉塊泡麵不可，素食/海鮮/蔬菜口味可；含豬油糕餅可（經熬製精煉之食用動物油脂） | 防檢署／關務署 |
| 肉品罰則 | 未申報遭查獲**第一次 20 萬元、第二次以後 100 萬元** | 農業部 |
| 食品量 | 單一品項須 <US$1,000 且 ≤6kg；部分集運商食品限 5kg | 集運業者 |
| 液體/噴霧藥妝（**出境日本**） | 單件 ≤0.5L/0.5kg，**合計 ≤2L/2kg**；彩妝不在此限 | 國土交通省 |
| 噴霧香水 | 含酒精屬易燃液體，**一律禁運**（集運） | 集運業者 |
| OTC 醫藥品（集運） | 單件 ≤0.5L/0.5kg，總量 ≤2L/2kg | 集運業者 |

### 3.4 T2 判定：**不通過（PARTIAL）**

在「台灣人最常託帶」的品項裡，網路買不到的比例**目測低於 30%**，而且那批（地域/期間限定零食）單價只有 **NT$50–200**——**單件價值低於一次超商店到店的 NT$60**。缺口是真的，但缺口裡的東西太便宜。

⚠️ 這是 PARTIAL 判定：我沒能逐項查 20 品在 Amazon.jp／樂天的實際 listing（網路被封）。**這一題應該由你自己或朋友花 1 小時實查，是全案最便宜的關鍵資料。**

## 4. T1＋T2 合併推論：商品單位錯了

單件經濟必死——一件 NT$150 的地域限定零食，光店到店就吃掉 40%。但把單位從「一件」換成「**一趟**」，數字會動：

**假設試算（非查證，用於示範結構）**：札幌 5 天，旅客可用 8kg，接 12 件、分屬 4 位買家，商品總額 ¥30,000≈NT$6,300

| 項目 | 金額 |
|---|---|
| 服務費 15% | NT$945 |
| 旅客分 60% | NT$567 → **每公斤約 NT$95** |
| 平台分 40% | NT$378 |
| 例外處理準備（4 買家 × NT$150） | −NT$600 |
| **平台淨** | **−NT$222** |

兩個數字同時出問題：
1. **旅客拿到的等效報酬 NT$95/kg，低於集運 NT$100/kg 的公定價**——他自己寄都比較划算，憑什麼替你扛？
2. 平台在 15% 費率下是負的。要轉正，**服務費率必須 >25%**（就撞到集運與蝦皮代購的價格），或**例外成本壓到 NT$50 以下**，或**客單價拉高**（就回到稀缺品）。

**三者只能靠品類選擇解決，而 §2 說了品類選擇是一把剪刀。這是 T1/T2 真正的產出。**

還有一個新增的逆風：**日本退稅新制 2026-11-01 上路**——改「先付後退」，店內不再現場折抵，一律到機場退稅；取消單日 50 萬日圓上限；免稅品須購買後 90 天內攜出。對本模式的直接衝擊是**旅客墊資金額增加 10%，且退款延後到機場**，讓「平台預撥／虛擬卡」從 nice-to-have 變成必要條件。（代購他人商品是否符合免稅要件仍**未查證**，列為法遵必辦。）

## 5. 兩條路（資料逼出來的分岔）

| | **A 路：承認稀缺才有錢** | **B 路：堅持日常品** |
|---|---|---|
| 品類 | 一番賞／角色周邊／園區限定（1.7–4× 溢價實證） | 地域限定零食＋彩妝（唯一沒撞 2kg 的縫隙） |
| 代價 | **推翻你上一輪的重新定位**，且回到 v1 審查的排隊/黃牛問題 | 費率必須 >25%，例外成本必須 <NT$50，且旅客報酬要低於 NT$95/kg 才成立 |
| 產品形態 | 有溢價可分，可以做重（保證、承保、信用分） | 只能做輕：**行程佈告欄＋信任層**，收 NT$30–50/件靠量 |
| 真實類比 | JPNJP／蝦皮代購賣家 | Craigslist／社團工具，**不是 Uber** |

我的建議：**先花一小時把 T2 補完**（20 品逐項查 Amazon.jp／樂天）。若「網路買不到」的比例真的 <30%，B 路在數學上關門，那就不是選擇題了。

# 6. User Journey — 買家端（下單方）

## 6.1 一句話：買家不是逛商品目錄，是**挑一班車**

這是本設計最重要的反轉。因為供給碎片化且**一次性**（一個旅客一趟只服務一次），需求驅動（先發需求再找人）會大量跳票。所以首頁是**本週出發的行程列表**，不是商品列表。

```
【首頁】本週出發
┌──────────────────────────────┐
│ 8/12 → 札幌 5天   剩 6.2kg  已接 8 件  截止 8/10 │
│ 8/14 → 東京 4天   剩 11kg   已接 3 件  截止 8/12 │
│ 8/15 → 沖繩 3天   剩 4kg    已接 12 件 截止 8/13 │
└──────────────────────────────┘
```

## 6.2 完整流程

| # | 階段 | 買家看到／做的事 | 背後的機制（對應 v2 設計節點） |
|---|---|---|---|
| 1 | **發現** | 挑一班有去他要的城市的行程 | 地理錯配是唯一能贏「問朋友」的地方（v2 §楔子） |
| 2 | **下單** | 填品項：**商品照片＋JAN/型號＋店名或「任一家」＋數量** | D4 責任分割線：條碼比對失敗不撥款 |
| 3 | **即時法遵擋** | 打含肉商品 → 紅字「此品項禁止輸入台灣，違規最高罰 100 萬」直接擋下單；打防曬 → 顯示「這班車液體額度剩 0.4kg」 | T6 黑名單 + 2kg 額度即時扣減。**這一步不能放在客服，必須在下單當下** |
| 4 | **報價** | 商品估價 ＋ 服務費 ＋ 店到店 NT$60 ＋ 例外準備金，**一次顯示到手總價** | 讓買家能直接跟集運/蝦皮比，比不贏就別做 |
| 5 | **湊件提示** | 「再加 2 件，每件運費從 NT$60 降到 NT$20」 | §4 的併單是唯一讓單位經濟為正的槓桿 |
| 6 | **付款** | 全額預付**到履約保證專戶**（不是平台帳戶） | 資金池＝代收代付，在台涉第三方支付/電支法遵紅線。初版一律掛靠既有金流商 |
| 7 | **等待** | 狀態列：已接單 → 已抵達城市 → **已購得／缺貨／限購** → 已入行李 → 已落地 → 已寄出（單號） → 取貨碼 | D2 結案狀態機 |
| 8 | **例外（最高頻結局）** | 缺貨 → 自動全額退＋一鍵「轉到下一班車」；限購 → 部分履行、差額自動退 | **缺貨不是異常流程，是主流程分支**，UI 必須平等對待 |
| 9 | **收貨** | 超商取貨 → 7 日內確認，或自動放行 | escrow 撥款觸發點 |
| 10 | **再購** | 「追蹤這位旅客的下一趟」＋「訂閱札幌路線」 | 防繞過的**正向**做法：讓留在平台比私下 LINE 更方便（日常品是重複購買，繞過誘因最強） |

## 6.3 買家端三個必須寫進 UI 的殘酷事實

1. **不保證買得到**——文案要主動說，不能藏在條款。承諾成功率就回到 v1 已被證偽的路。
2. **液體額度會賣完**——這是真的物理上限，不是庫存話術，要顯示得像機位一樣。
3. **時間由行程決定**——買家不能指定何時到貨，只能挑車。這是本模式相對集運**唯一的劣勢**，藏起來只會換到客訴。

# 7. User Journey — 旅客端（幫買方）

## 7.1 一句話：他不是接案，是**把已經買好的機票變現一點**

動機不是賺錢，是「回本一點」。任何要求他為了訂單改變行程的設計都會失敗——這是 v1 審查的核心教訓（「順便」與「專職」互斥）。

## 7.2 完整流程

| # | 階段 | 旅客看到／做的事 | 背後的機制 |
|---|---|---|---|
| 1 | **登錄行程** | 城市、日期、回程航班、**可用行李額度 kg** | 供給的單位是「趟」不是「人」 |
| 2 | **自用額度自宣告** | 「你自己要買多少液體藥妝？」→ 從 2kg 總量扣掉，剩下才可接單 | **這一步不做，就會在機場當場被攔下**。2L/2kg 是與自購合併計算 |
| 3 | **看單池** | 只看得到綁在自己這趟行程上的單，預設**按「是否順路」排序**（用他填的飯店/景點推算） | 繞路是成本，排序就是產品 |
| 4 | **打包接單** | 一次接 N 單 → 系統自動合併成**一張按店家分組、按地圖動線排序的採買清單** | 併單是單位經濟唯一的槓桿（§4） |
| 5 | **墊資** | 平台預撥虛擬卡（限單店＋單次＋金額上限＋當日有效）；不得已才自墊 | **退稅新制「先付後退」讓自墊多壓 10% 且退款延到機場**，虛擬卡從選配變必要 |
| 6 | **現場** | 掃 JAN 條碼比對 → 系統確認同一品項 → 拍照 → 一鍵標記 **已購得／缺貨／限購／拒賣** | D3 墊資控制 + D2 狀態機。四個結局在 UI 上等權重 |
| 7 | **打包封存** | 登機前上傳「所有代買品＋行李」合照 | D4 責任分割線：此刻起貨損歸物流不歸他 |
| 8 | **落地寄件** | 一次列印所有超商店到店單 → 一趟寄完 → 上傳單號 | 把交貨成本從 N 趟壓成 1 趟 |
| 9 | **撥款** | 買家確認或 7 日自動放行 → 服務費入帳 | escrow |
| 10 | **信用分** | 三軸：成功率／接單後放鴿率／證據合規率 → 決定下一趟可接的單量、金額上限、能否看到高價單 | D7。低分看不到好單，是唯一有效的供給端治理 |

## 7.3 旅客端三個會殺死留存的細節

1. **接單後才發現要繞路** → 排序演算法若不準，第一趟就流失。冷啟動階段建議**人工排單**，不要先寫演算法。
2. **墊資後現金卡住** → 虛擬卡沒過，就得自墊 ¥30,000 等回台再撥。這是 V3 虛擬卡實地測試必須先做完的原因（超市／便利商店／藥妝店的小額受理率是全案地基）。
3. **落地後還要跑一趟超商** → 這是他心裡「順便」破功的瞬間。設計上要允許「委託家人寄」或「機場寄件櫃」，並把這段成本明碼標在報酬裡。

## 7.4 兩端的關鍵不對稱（設計時反覆回來看這句）

> **買家在意「拿不拿得到、多少錢」；旅客在意「會不會麻煩」。**
> 買家的痛可以用錢解，旅客的痛不行——加價買不到「不繞路」。所以所有機制設計，**降低旅客麻煩 > 提高旅客報酬**。
