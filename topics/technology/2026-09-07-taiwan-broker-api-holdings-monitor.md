# 台股券商 API：能不能自動知道我的持倉變化

> **提問（2026-09-07 Jake）**：「券商 API 我想知道台灣有哪些能夠接的，
> 讓我們可以即時或是自動知道我的持倉變化。」
>
> **前情**：Google Sheet 方案（2026-08-20 建立）**已失敗**——它一樣要 Jake 手動更新，
> 目前停在 08-20，比 repo 還舊。失敗原因與它原本要解決的問題**完全相同**：需要他記得。

---

## 一、一句話結論

**永豐 Shioaji 是唯一符合全部條件的選項**（Python、macOS 原生、有 `list_positions()`、免費）。
但**帳務資料需要電子憑證且憑證必須保留在本地端** ⇒ **只能跑在 Jake 的 Mac，不能跑在 GitHub Actions runner**。
「即時」在實務上做不到也不需要，**「每日一次快照 + 差異偵測」才是對的規格**。

---

## 二、候選清單與淘汰理由

| 券商 | API | 語言 | macOS | 能查庫存？ | 判定 |
|---|---|---|---|---|---|
| **永豐 SinoPac** | **Shioaji** | **Python**（另有 HTTP API → JS/Go/C#/Rust/Java） | ✅ **官方跨平台 Win/Linux/Mac** | ✅ `list_positions()`：代碼／數量／均價／現價／損益 | ⭐ **首選** |
| 富邦 | **Neo API** | Python / Node.js / C# | ⚠️ 需確認 | ✅ | 🥈 備案 |
| 群益 | 策略王 API | Windows COM | ❌ | ✅ | **淘汰：Mac 不可用** |
| 凱基 | TradeCom API | Windows COM | ❌ | ✅ | **淘汰：Mac 不可用** |
| 元大／統一／康和／國票 | 各家 | 多為 Windows、期貨導向 | ❌／⚠️ | — | **淘汰或不優先** |

> 📌 **決定性的篩選條件不是功能，是作業系統。**
> 群益與凱基是 Windows COM 元件架構，**在 macOS 上根本裝不起來**——
> 這一條就砍掉一半候選，不需要比較 API 好不好用。
> 社群使用經驗（用過群益／凱基／永豐三家）也一致指向永豐最貼近程式設計思維 `[推論：單一來源]`。

---

## 三、🔴 決定性的架構約束：憑證只能放本地

永豐官方說明：**個資相關資料（下單、帳務）除登入驗證外，還需電子憑證驗證；
客戶需先下載電子憑證並「保留在本地端」，經 API 憑證驗證後才能取得帳務資料。**

推論鏈：

```
帳務資料需要電子憑證
  → 憑證必須存在本地檔案系統
    → GitHub Actions runner 是每次全新、無狀態的容器
      → 要跑在 runner 上，就必須把憑證放進 repo secret
        → 那等於把「下單權限」交給雲端
          → ❌ 對一個在職銀行從業人員，不建議；也不該為了方便而做
```

> **結論：這支程式只能跑在 Jake 的 Mac 上。**
> 這不是「目前還沒做」，是**架構上的定案**——請不要在未來 session 重新討論把它搬上雲端。

---

## 四、「即時」是錯的規格

Shioaji 有委託／成交回報的 callback，理論上可以「即時」。但：

- callback **只在程式持續運行且連線時有效**；Mac 會睡眠、會關機、會斷網。
- 追求即時 ⇒ 要維護一個常駐服務 ⇒ **維護成本遠高於它解決的問題**。
- 真正要解決的問題是「**Jake 忘記說**」，而那個問題**用每日一次就完全解決了**。

> ✅ **正確規格：每日收盤後跑一次，抓庫存快照，與前一份比對，有變動才寫檔。**
> 這對「Claude 下次開場就知道最新部位」而言，**延遲上限是一個交易日**——完全夠用。

---

## 五、建議實作（**限制在一天內做完**）

⚠️ **誠實提醒：這正是「開坑成癮」的形狀。**（每月自檢第 7 題：深掘 ÷ 執行 >5:1 ＝研究代償）
所以刻意把範圍壓到最小，**先不做 UI、圖表、即時推播**。

### Phase 1（Mac 本地，約半天）

1. `pip install shioaji`，下載並安裝永豐電子憑證
2. 一支 script：`login()` → `list_positions()` → 寫成 `skills/serenity/holdings_auto.json`
3. 與上一份 diff，**有變動才** `git commit && git push`
4. `launchd` 每個交易日收盤後跑一次（台股 14:00 後）

**驗收條件**（必須是「內容正確」，不是「檔案存在」——見 `agents/LEARNINGS.md` 的 irbank 教訓）：
> 產出的 JSON 裡 **8271 的股數是 3,000、均價約 NT$240.342**，且 **2303 是 4,000 股 @NT$122**。
> 對不上就是壞的，不要因為檔案生出來了就當成功。

### Phase 2（美股，等 IBKR 開戶後）

COHX／BE 走 **IBKR API**（需本機跑 TWS/Gateway，同樣是本地約束）。
BVI 基金架構已定案要用 IBKR，**遲早都在那裡**，不必為此另外開一條路。

### 明確不做

即時推播、Web UI、圖表、下單功能。**這支程式只讀不寫（帳戶端）。**
