# 前瞻本益比模型：第一性原理設計

> ⚠️ **這是驗證前寫下的設計。回測推翻了其中兩個模組，最終版見 README §2、§4：**
> - 模組 U（信念溢價會衰減）：γ12 每年都是 +0.00～+0.05，**股價不向 V 修正** → 刪除，報酬改成外生假設（預設資金成本）。
> - 模組 V（DCF 解釋倍數）：用歷史利潤率時與橫斷面本益比的相關 −0.38～+0.05（README 表 9） → **改成倒過來用**，
>   反推「市場隱含的長期淨利率」，再把它接回模組 E 當輸入（兩階段）。
> - 模組 E 與 §1 的恆等式、§5 的驗證規則、§6 的否證條件維持不變，並且都照做了。

> 上一版（`projects/pe-model/`，在 `claude/macro-economy-asset-forecast` 分支）回答的是：
> 「這個總體環境撐得起**大盤**幾倍」。它有三個結構性限制，正好是這一版要解決的問題：
> ① 係數來自過去 70 年的平均關係，無法表達「這個產業正在改變結構」；
> ② 只有市場層，**個別公司的差異**（GOOGL vs MSFT、MU vs SNDK）無從解釋；
> ③ 它是定價模型不是預測模型——12 個月的樣本外 R² 只有 0.06。
>
> 這一版不問「歷史上這種公司平均幾倍」，而問：**本益比是由哪些實體量決定的？
> 哪些量在今天就看得到、而且能推算到 6–36 個月後？**

---

## 1. 從恆等式開始（不是從迴歸開始）

本益比是兩個數的比值，不是一個獨立存在的東西：

```
PE(t) = P(t) / E(t)            E = 過去四季 EPS（TTM）
```

**恆等式 1（時間差分）：** 取 log，對 h 個月做差分：

```
ln PE(t+h) − ln PE(t)  =  [ln P(t+h) − ln P(t)]  −  [ln E(t+h) − ln E(t)]
                        =        股價報酬 ρ          −      盈餘成長 γ
```

這一行決定了整個模型的形狀：

- **本益比的變化只有兩個來源：股價報酬和盈餘成長。** 沒有第三個。
- 股價報酬在 6–12 個月內**幾乎無法預測**（否則大家都會去套利），它的期望值約等於資金成本。
- 盈餘成長**大部分可以預測**——營收有慣性、毛利率有均值回歸、存貨和產能有物理延遲。
- ⇒ **本益比能被預測的部分，幾乎全部來自「預測盈餘」**。模型的核心是盈餘路徑，不是倍數。

這直接解釋了為什麼記憶體是好例子：記憶體的 `γ` 動輒 ±100%，遠大於 `ρ` 的雜訊，
所以只要能預測盈餘，就能預測本益比。MSFT 的 `γ` 每年穩定在 10–20%，
本益比變化主要來自 `ρ`（情緒、利率），本質上比較難預測。**模型會把每家公司的
Var(ρ)、Var(γ) 拆出來給你看，你就知道這家公司的本益比「可預測程度」有多高。**

**恆等式 2（價值分解）：** 股價是未來現金流的現值。把它寫成：

```
P(t) = V(t) × exp(u(t))

V(t) = Σ_k  FCF_k / (1+r)^k        ← 用「今天看得到的資料」推出來的內在價值
u(t) = ln P(t) − ln V(t)           ← 市場多付（或少付）的部分：信念、敘事、模型沒看到的東西
```

代回本益比：

```
ln PE(t+h) = ln V(t+h) − ln E(t+h) + u(t+h)
             └──── 基本面倍數 ────┘   └ 信念溢價 ┘
```

三個模組就從這裡長出來。

## 2. 三個模組

### 模組 E：盈餘路徑（最重要）

不直接預測 EPS 成長率（EPS 會跨越零、成長率會無限大），而是拆成實體量：

```
EPS = 營收 × 淨利率 ÷ 股數
```

| 量 | 物理意義 | 今天看得到的領先訊號 |
|---|---|---|
| 營收成長 | 需求 × 價格 | 近 4 季 YoY 成長（慣性）、最新一季相對 TTM 的加速度 |
| 淨利率 | 價格 vs 成本、營運槓桿 | 目前毛利率 vs 自身結構水準（均值回歸）、毛利率近兩季斜率（報價慣性）、存貨天數變化（供過於求的前兆） |
| 股數 | 回購／稀釋 | 近 4 季股數變化率 |

- **係數用整個面板（所有公司）估**，不是每個產業各估一組——物理規律（存貨堆積 → 降價 → 毛利率跌）
  對所有公司一樣，差別在「各家的訊號值」不同。這是它能套用到新公司、新結構的原因。
- 「結構水準」（毛利率、淨利率往哪裡回歸）＝該公司**近 5 年**的中位數，**會隨時間移動**。
  記憶體若真的脫離循環，高毛利會持續、結構水準會被拉上去，模型自然跟著更新；
  你也可以直接用參數覆寫它（見 §4 的情境輸入）。

### 模組 V：基本面倍數（內在價值 ÷ 盈餘）

最小的 DCF，只有第一性原理的量：

```
營收路徑：  模組 E 的預測（前 12 季）→ 之後成長率以半衰期 H 衰退到長期成長 g∞
淨利率路徑：模組 E 的預測 → 之後以同一速度收斂到結構淨利率 m̄
再投資：    每多 1 元營收要投入 1/(S/C) 元資本（S/C = 營收 ÷ 投入資本，公司自己的數字）
FCF_k    =  盈餘_k − 營收增量_k ÷ (S/C)
折現率   r = 10 年期殖利率 + 風險溢酬
風險溢酬   = θ₀ + θ₁ × σ（公司自己的利潤率波動＝現金流不確定性）
終值      =  第 10 年 FCF 以 g∞ 永續
```

這一段把「為什麼同產業兩家公司倍數不同」變成可計算的量：

- **成長**：營收成長快、而且看得到慣性 → 分子大。
- **資本效率**：S/C 高的公司，成長不用花太多錢，同樣的盈餘能發更多現金 → 倍數高。
- **確定性**：利潤率波動 σ 大（典型記憶體）→ 折現率高 → 倍數低。**σ 是用公司最近幾年自己的
  資料算的**，所以如果記憶體真的變得不循環（HBM 長約、預付款、供給紀律），σ 會下降、倍數會上升——
  **模型不需要被告知「產業變了」，它從資料裡看到**。
- **週期位置**：盈餘在高峰時，模組 E 預測它會回落，V 裡的未來盈餘比今天低 → PE（對 TTM）低；
  谷底時相反 → PE 高。這就是「記憶體在高峰本益比最低」的機制，從現金流推出來，不是從歷史 PE 背出來。

θ₀、θ₁、H 是全市場共用的少數「物理常數」，用**當時為止**的資料校準（讓 V 與市價的平均誤差最小），
每 12 個月重估一次。

### 模組 U：信念溢價的衰減

`u = ln P − ln V` 是市場願意多付的部分（GOOGL 的搜尋被顛覆風險、MSFT 的雲端護城河、
NVDA 的 AI 期權價值……模型的 DCF 沒看到的東西都在這裡）。

- 它不是雜訊：**同一家公司的 u 有很強的持續性**。這正是「同產業不同倍數」裡模型解釋不了的剩餘部分。
- 它也不是常數：u 會部分回歸。回歸速度 `u(t+h) = λ_h × u(t)` 用過去的資料估。
- λ_h = 1 等於「股價隨機漫步」（純效率市場）；λ_h = 0 等於「股價一定回到內在價值」。
  **估出來的 λ_h 就是這個市場到底有多相信基本面的實測值。**

## 3. 預測公式

在時點 t、預測 h 個月後：

```
1. 模組 E 產生盈餘路徑 Ê(t+1 … t+h+40季)
2. 在 t+h 的位置重算 V̂(t+h)：用 t+h 時「預期會看到的」營收、利潤率、殖利率（預設維持今天，可覆寫）
3. û(t+h) = λ_h × u(t)
4. P̂E(t+h) = V̂(t+h) × exp(û(t+h)) ÷ Ê_TTM(t+h)
```

對負盈餘：同時輸出盈餘殖利率 E/P（跨越零時連續），評估也同時看 ln PE（盈餘為正時）與 E/P。

## 4. 模組化：什麼可以換

| 輸入 | 預設 | 用途 |
|---|---|---|
| 公司、時點 | 任意 ticker、任意歷史月份 | 回到過去某一天，只用那天看得到的資料 |
| 殖利率路徑 | 維持當下 | 利率情境（接 macro-scenarios） |
| 營收成長覆寫 | 模組 E 預測 | 例：Serenity 分析給出的營收指引 |
| 結構淨利率 m̄ | 近 5 年中位數 | 例：「記憶體新結構的長期淨利率是 30%」 |
| 利潤率波動 σ | 近 5 年實測 | 例：「假設記憶體循環性降到晶圓代工水準」 |
| 長期成長 g∞、衰退半衰期 H | 校準值 | 敏感度分析 |
| 信念衰減 λ_h | 實測值 | 設 1 ＝ 不預期重估；設 0 ＝ 假設回到基本面 |

## 5. 怎麼驗證（避免自欺）

1. **時點正確（point-in-time）**：t 時點只能用 t 以前**已公告**的財報（有申報日用申報日，
   沒有就保守假設季末後 60 天才能用）與 t 以前的股價、殖利率。
2. **參數走動式估計（walk-forward）**：所有係數與常數只用 t 以前、且「t−h 的預測已經揭曉」的樣本估。
3. **預測距離**：h = 6、12、24、36 個月。「用 12 個月前的資料預測現在」＝ h=12 的最後一個點。
4. **基準線**（模型必須打敗才算有用）：
   - **隨機漫步**：PE(t+h) = PE(t)。
   - **歷史均值**（舊思維）：該公司過去 5 年平均 PE。
   - **同業中位數**：t 時點同產業的 PE 中位數。
5. **評分**：ln PE 的中位絕對誤差（≈ 誤差百分比）、方向命中率（PE 會升還是降）、
   橫斷面排序相關（同一天多家公司裡，誰的 PE 會比較高）、E/P 的平均絕對誤差。
6. **拆解**：分成「若盈餘預測完美」與「若股價完美」兩種 oracle 版本，看誤差來自哪個模組。

## 6. 預先寫下的否證條件

以下任一成立，就代表這個設計錯了，要換路：

- 12 個月預測的 ln PE 誤差**不比隨機漫步好** → 模組 E 沒有抓到可預測的盈餘成長。
- 模型只在循環股贏、在穩定成長股**輸給隨機漫步很多** → 要把兩類分開處理，不能共用一組常數。
- λ_h 估出來 ≈ 1 且 V 對未來股價沒有解釋力 → 模組 V 只是裝飾，應該拿掉，模型退化成「盈餘預測器」。
