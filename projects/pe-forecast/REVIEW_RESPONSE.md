## 1. 保留做對的部分

同意。審查用匯出資料重算 12 個月 41,566 筆、中位誤差 0.2272 vs「本益比不變」0.2686（−15.4%），和頁面摘要一致——這是舊的組合模型（沒有 EPS）的成績。

## 2. 預測目標的定義

✅ README §15.1 放了審查的三種本益比對照表，並寫明：這一版預測的是「目標日的 trailing 本益比 ＝ 那天的股價 ÷ 那天**已經公布**的最近四季 EPS」；
已經結束、但目標日之後才公布的那一季不算。回測標籤就是這個定義（`pef/cond.py` 的 `build`：目標日月底時的最近一季，`target_quarter_end` 欄位可查）。
網頁與 `target_price.py` 會依每家公司最新季末推算「那時大概已公布到哪一季」並印出來，告訴使用者要輸入哪四季的 EPS。

## 3. 回測可信度

**標籤成熟（最重要的一條）**——兩個模型都符合，而且每個預測距離分開篩：
- 給定 EPS 的模型：`pef/cond.py:181` assert 訓練配對的「t+h 那個月的月底」≤ 訓練截止日；`:182` assert 特徵的公告日 ≤ 預測起點月底。
  同一個月份的所有公司一起切（每年 1 月整批重估）。區間校準只用截止日以前已揭曉的誤差（`calib_table`；走動式評估 `lab_cond.py` 的 `interval_eval`）。
  「去掉大盤」用的同月份中位數只在已揭曉的訓練標籤上算。
- 組合模型（沒有 EPS）：`pef/lab.py:194`、`pef/ensemble.py:51` 用同一條件（t+h ≤ asof）；盈餘模組 `pef/earnings.py:47` 要求 t+k 季財報的公告日 ≤ asof；
  區間 `pef/ensemble.py:82` 只用 asof 以前已揭曉的誤差。
- 順手修的小瑕疵：`target_available_at` 原本是「起點月底 ＋ h 個月」，2 月底起點會落在目標月的 28/29 日；改成目標月月底。
  訓練截止日都是月底，所以這個瑕疵從來沒有讓未揭曉的答案進入訓練；重跑後逐筆預測和修改前**完全相同**（最大差 0）。

**期間**：✅ README §15.4 寫明——股價資料到 2025-09；選模期＝預測起點 2015–2021；保留期起點 12 個月 2022-01～2024-09（33 個月份）、
24 個月到 2023-09（21 個）、36 個月只有 2022-01～2022-09（9 個，實際上是同一段行情，不能用公司筆數代替跨景氣驗證）。

**2025-12→2026-09 的近期驗證**：🔬 沒有前視。訓練面板（`panel_sp500()`）最後一個月是 2025-09，所有訓練答案都在 2025-09 以前揭曉；
2026-09-30 只是傳給 `fit` 的上限。網頁說明「用 2026-09-30 以前已揭曉的資料訓練」字面正確但會誤導，已改寫；`lab_window.py:102` 加了 assert。
那一段的財報是事後重述值、成分股是 2026-09 名單——這兩點原本就揭露了。

**中小型股回測**：↔ 同意它不是嚴格的歷史樣本外（重述後財報、2026 年名單、ETF 持股推回的股價）；README §14.6 與網頁原本就這樣寫。
要改進需要當時可得的財報、當時的股票全集與下市資料，免費來源沒有，這一輪不做。

**S&P 500 名單的倖存者偏誤**：🔬 用 github.com/fja05680/sp500 的歷史成分股（`data/sp500_membership_spells.csv`；改過代號的 20 家（23 個舊代號）對回舊代號，每組都核對過
「舊代號離開那天＝新代號加入那天」，`pef/universe.py`）把回測分成「預測當時已是成分股」和「之後才加入」。
給定 EPS 的模型，只看當時已是成分股：12 個月 xs 相對資金成本 選模期 +0.1%、保留期 −2.5%；24 個月保留期 −9.1%；36 個月 −11.8%——結論不變。
之後才加入的公司股價漲得多（12 個月中位 +23% vs +10%）、誤差也大。查不到的另一半：之後被踢出指數的公司不在資料裡，回測因此偏樂觀（README §15.4、§15.11）。

**SEC 申報版本**：↔ S&P 500 回測用的是 companyfacts 原始 JSON 裡**第一次申報**的值與它的申報日（`pef/data.py:60` `_first_filed`），不是 frames API 的最後申報值；
早年（XBRL 以前）的季度，第一次出現在 XBRL 的日期比實際公告晚，可得日因此偏保守（不會前視）。accession 編號原始 JSON 有，建表時沒留——見 §9。

## 4. 誤差、區間與 R² 的口徑

- **誤差不對稱**：✅ `pm()` 改成 e^(±x)：中位 |ln 誤差| 0.2271 → 「一半落在預測的 0.80–1.25 倍」（`artifact/page.html:503`）。
- **±20%**：✅ 舊模型的欄位改名為「落在實際 0.83–1.2 倍」（即 |ln(預測 ÷ 實際)| ≤ ln 1.2，和原本的算法一致）；新模型改用一般人理解的
  |預測 ÷ 實際 − 1| ≤ 20%，兩者在表頭寫清楚，不混用。
- **80% 區間**：✅ 改寫成「名目 80%，實測…」，並說明大盤整年偏一邊時會更多落在區間外。新模型另外重做了區間（§7 第 6 項）。
- **R²**：↔ 舊模型頁面的 R² 是 1 − Σmin(e², 4) ÷ Σmin(e_不變², 4)（誤差平方截在 4），公式已寫在表下；審查重算的 0.3722 是不截尾、用四捨五入後的匯出值，
  兩者口徑不同，不是錯誤。新模型的「技能」一律不截尾：1 − Σe² ÷ Σe_資金成本²（README §15.4）。
- **方向**：✅ 平手算錯（寫在頁面）。基準（`review_checks.py`）：12 個月組合模型 66%（選模期）／68%（保留期），「永遠猜會跌」51%／49%、「永遠猜會漲」49%／51%；
  36 個月 64%／72% vs 52%／46% 與 48%／54%。這是本益比方向，不是選股報酬。
- **月份區塊自助法**：✅ 同一個月的所有公司一起抽；另外做「連續 L 個月」的移動區塊，處理相鄰起點答案期間重疊（README §15.4 表）。

## 5. 「模型預期淨利」

✅ 同意這是反算值。網頁改名「等效隱含淨利」並寫明「用本益比和資金成本反推，不是獨立的盈餘預測」（`artifact/page.html` 的 `implNi` 與案例說明）；
組合是對數平均（＝本益比的幾何平均）也寫在「模型邏輯」分頁。MU 2025-09 案例的兩個大誤差互相抵銷，頁面不再把它說成盈餘預測成功。
真正獨立的淨利預測評分（盈餘模組單獨評分）這一輪沒做；給定 EPS 的新模型不需要它（盈餘由使用者給）。

## 6. 資金成本與股價、市值

- ✅ 新模型全部改用**每股**：股數＝市值 ÷ 股價（同一天），本益比＝股價 ÷ EPS＝市值 ÷ 淨利，兩個寫法完全相等；回購、增發的影響在 EPS 裡。
- ✅ 股利：價格報酬不含股利。試了「資金成本扣殖利率」（coe_dy）：選模期較差（+2.2%）、保留期較好（−1.6%），不穩定；
  新模型的相對大盤部分直接學到殖利率的影響（12 個月係數 −1.68：殖利率 3% → 相對 −5%）。
- ✅ 連續複利：網頁「模型邏輯」標示 9.6% 是連續複利、一年實際約 +10.1%；「輸入 EPS」分頁的拆解也標示。
- 舊模型（組合）用的是市值 ÷ 淨利；網頁案例表把「市值（股價）」改成「市值」，並說明回購、增發會讓兩者分開。
- ↔ 審查說「不能推出股價任何部分都無法預測」——同意。新模型的相對大盤部分就是可預測的那一小塊（24–36 個月才明顯）；
  但直接預測大盤的版本在保留期失效（README §15.4 表 15-3）。

## 8. 其他判讀

- **73–91%**：✅ 寫出公式（盈餘成長變異 ÷〔股價報酬變異 ＋ 盈餘成長變異〕，各公司算完取產業中位數），註明沒算共變異、不是「可預測的比例」（網頁「模型邏輯」、README §1 表 5 的定義在 `pef/backtest.py` 的 `decompose`）。
- **oracle 不是下限**：✅ 改寫成「那個股價假設下的結果，不是任何模型的下限」；新模型在同樣知道盈餘時確實又小幅改善了（README 表 15-1）。
- **營業利益 × 0.85**：✅ 標成簡化代理（沒扣利息、固定稅率、沒處理少數股權），不是更真實的盈餘。
- **>500、虧損、資料不足**：✅ 分開顯示「虧損」「>500」「—」。
- **台積電**：✅ 改成「向 SEC 交 20-F 年報、季度財報另外發布，資料管線抓不到——是資料涵蓋問題，不是公司沒有季報」（網頁、README §13.5、§14.6、`now_run.py`）。
- **保留期被看過**：✅ 同意。新模型「只學相對大盤」的設計是看過保留期逐年結果後才定的，已在 README §15.4、`lab_cond.py` 開頭與網頁揭露。
  真正的樣本外：`forward_log.py freeze` 已把 2026-09-24 的輸入（3,072 家）和模型凍結在 `results/forward/2026-09-24/`；
  事先寫好的採用條件：12 個月 xs 在 S&P 500 上不比資金成本差、80% 區間涵蓋在 70–90% 之間，才繼續當正式版（README §15.9）。36 個月要等到 2029 年。
