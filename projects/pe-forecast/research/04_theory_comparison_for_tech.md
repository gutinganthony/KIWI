# 第 1 步之二：哪個本益比理論最適合科技成長股？（2026-10-06）

## 1. 科技股和一般股票不一樣的地方

| # | 特性 | 為什麼重要 |
|---|---|---|
| ① | 高成長只維持有限年數，之後被競爭追上 | 永續成長公式（Gordon）不適用；本益比會隨高成長年數被「用掉」而下降 |
| ② | 研發、股權報酬（SBC）費用化 | EPS 被壓低（研發加速期）或虛高（研發放緩期），帳面淨值被低估 |
| ③ | 成長的不確定性高 | 價值對成長率是凸函數，不確定性本身推高今天的價格（Pástor-Veronesi） |
| ④ | 不配息或少配息、大量買回 | 股利模型只剩終值；帳面淨值很小甚至為負 |
| ⑤ | 半導體、記憶體有景氣循環 | 景氣高點的低本益比是暫時性高盈餘造成的（Molodovsky／Penman） |
| ⑥ | 部分公司虧損 | EPS ≤ 0 時本益比沒有定義；網路股研究發現盈餘根本不被定價 |
| ⑦ | 股價大部分是「成長機會」 | 不成長的本益比只有 1/r ≈ 10.4 倍；30–35 倍的科技股，65–70% 的價格來自成長機會（試算） |

## 3. 數值試算：三種典型科技公司（r＝9.6%；示意，不是預測）

| | A 穩定巨頭（MSFT/AAPL 型） | B 高成長（NVDA 型） | C 週期高點（MU 型） |
|---|---|---|---|
| 假設 | forward P/E 30、下一年 EPS ＋12%、ROE 35% | forward P/E 35、下一年 EPS ＋35%、ROE 50% | forward P/E 10、下一年 EPS −20% |
| 股價裡「成長機會」占比（MM） | 65% | 70% | −4% |
| Gordon 隱含永續成長 | 6.9% | 7.2% | −0.6% |
| Gordon：r ∓1 個百分點 | 本益比 48／22（+60%／−27%） | 59／25（+69%／−29%） | 11／9 |
| AEG 隱含長期異常成長 | +6.8% | −1.2% | 解不出來 |
| 兩階段：今天價格隱含的高成長年數 | 約 15 年（12%） | 約 4 年（35%） | — |
| **預期不變時 forward 本益比軌道（今天 → 1 → 2 → 3 年）** | 30.3 → 29.0 → 27.8 → 26.7 | **34.4 → 27.7 → 22.3 → 17.9** | 用再下一年 EPS 算是 12.5 倍（低本益比是暫時的） |

讀法：
- 高成長股只要一年後市場的長期看法沒變，forward 本益比會**機械性地掉約 19%**；穩定巨頭只掉約 4%。
  舊模型的實證（EPS 成長 82% 以上的公司，12 個月本益比中位數 −58%）和這個方向一致。
- Gordon 對 r 太敏感，只能當「最後的成熟期」用。
- 週期股要先處理暫時性盈餘，AEG 在 EPS 下滑時不能用。

## 4. 實證怎麼說（摘要，詳見 02、03）

- **模型賽馬的結論是「終值和衰減假設」比「選哪個模型」重要**：一致實作時，DCF 和剩餘收益模型給出完全相同的價值（Lundholm-O'Keefe 2001）；
  終值用市場價格基礎的預測，大幅勝過任意設定的永續成長率（Courteau-Kao-Richardson 2001）。
- **剩餘收益模型全樣本最準，但在高本益比、高股價淨值比的公司表現差**（Penman-Sougiannis 1998，二手）；AEG 一般又不如剩餘收益模型，差在預測期之後的成長假設（Jorgensen-Lee-Yoo 2011）。
  → 科技股上**沒有已被證明最準的會計模型**。
- **forward 盈餘倍數最準，且各產業排名一樣**（Liu-Nissim-Thomas 2002）→ 科技股不需要「專用倍數」，需要的是把成長年數與衰減講清楚。
- **科技股估值誤差本來就大**：唯一的科技股大樣本賽馬裡，營收倍數的中位誤差約 59%（Klobucnik-Sievers 2013，二手數字）。
- **盈餘成長幾乎不持續、分析師長期預估偏樂觀**（Chan-Karceski-Lakonishok 2003：預估中位 14.5%、實現約 9%，二手數字）→ 使用者給的 EPS 路徑若來自共識，應有「打折」選項。
- **研發偏誤會變號**：研發加速的公司 GAAP EPS 偏保守（被低估）、研發放緩的成熟公司偏激進（被高估）（Lev-Sarath-Sougiannis 2005）。
- **不確定性與學習**：年輕、不配息公司倍數較高，但隨年齡下降更快（Pástor-Veronesi 2003）。

## 5. 結論：科技股本益比模型的骨架（判斷）

**主體：AEG（Ohlson-Juettner-Nauroth）／多階段盈餘模型＋ Leibowitz 本益比軌道。**理由：
1. 它**只需要 EPS**，正好是你會提供的輸入（下一年、再下一年 EPS，加一個長期成長）；不需要被買回與研發費用化扭曲的帳面淨值。
   這是不選剩餘收益模型當主體的原因——剩餘收益模型的優勢建立在全樣本，在高本益比公司反而差，而且大型科技股的帳面淨值常常很小甚至為負。
2. AEG 最大的弱點是「預測期之後的長期成長要假設」。**解法是不要假設，用今天的股價反推**（市場隱含的長期成長 γ 或高成長年數 n）。
   這也呼應實證：用價格基礎的終值，比任意設定的永續成長準。
3. 反推出市場的長期看法後，把時間往前推 12 個月、代入你的 EPS 路徑，就得到「**市場長期看法不變時，12 個月後的本益比**」（軌道）。
   實際本益比和軌道的差，就是「預期修正」：大盤折現率的變動（各股共同）＋成長看法的修正（個股）。

**依公司類型加上的修正：**
| 類型 | 修正 |
|---|---|
| 穩定巨頭、高成長獲利公司 | 主體直接用；EPS 用含 SBC 的 GAAP 稀釋；可另算研發資本化版本對照 |
| 半導體、記憶體週期股 | 先做盈餘正常化（Molodovsky／Penman），用跨週期的 EPS 判斷「暫時性」；景氣高點的低本益比不能直接外推 |
| 不確定性高（年輕、不配息、新題材） | EPS 路徑用情境或分布，不用單一路徑（Pástor-Veronesi 的凸性）；預期倍數隨不確定性解除而下降 |
| 虧損公司 | 不做本益比；改用營收模型（Schwartz-Moon 精簡版或 EV/Sales），之後另議 |

**Gordon 只當最後的成熟期；Campbell-Shiller／Vuolteenaho 恆等式用來拆解誤差（大盤共同部分 vs 個股部分），不當預測模型。**

**要打敗的基準**（不然新模型沒有存在價值）：
1. 「本益比不變」× 你的 EPS
2. 「同業 forward 本益比中位數」× 你的 EPS（Liu-Nissim-Thomas 的最強基準）
3. 分析師 12 個月目標價（平均絕對誤差約 45%，Bradshaw-Brown-Huang 2013）

## 6. 可以直接驗證的假說（下一步）

- **H1（軌道）**：高成長科技股，在 EPS 照預期實現時，12 個月後的 forward 本益比會往下收斂，幅度約等於「用掉一年高成長」的軌道值。
  可以用現有的科技股資料回測：用 t 時的股價反推隱含高成長年數（以事後實現的 EPS 路徑當作預期的代理），算出軌道，和實際 12 個月後的本益比比較。
- **H2（反推優於假設）**：用今天股價反推長期成長，比固定假設一個長期成長率更準。
- **H3（週期修正）**：記憶體、半導體設備在景氣高點時，用正常化 EPS 算的軌道比直接用當期 EPS 準。
