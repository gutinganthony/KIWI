# 情境機率模型 — 給讀者的簡單說明

> 這份可以直接轉貼給問「那些機率哪來的」的人。
> 完整程式在 `scenario_model.py`，跑 `python3 scenario_model.py --info` 會印出全部細節。

---

## 一句話版本

**我不猜「會發生哪個情境」，我只猜三件可以去查的事，再用明文規則把它們組合成情境。**

就像氣象預報不會直接猜「明天野餐會不會成功」，而是先估下不下雨、風大不大，再推出結論。

---

## 三個輸入，以及每個數字怎麼來的

| 變數 | 狀態與機率 | 這個數字的依據 | 什麼讀數會讓我改它 |
|---|---|---|---|
| **油價** | 回落 35%／黏著 50%／飆破 $115 15% | 戰爭溢價的歷史半衰期短；9/11 已傳出阿曼談判、當日油價 −2.8%；荷莫茲從未真正關閉，關閉是尾部 | Brent 現貨、談判進展、OPEC 閒置產能 |
| **核心通膨** | 溫和 48%／轉熱 52% | 當下三個月年化其實只有 2.0–2.4%，**但住房正由順風轉逆風**（新簽約租金 2 月 +1.9% → 8 月 +2.5%、空置率首度下降），而官方數字落後 3–4 季 | 核心 CPI／PCE 的三個月年化、ZORI 新簽約租金 |
| **就業** | 很強 20%／普通 55%／變差 25% | 非農三個月均約 7.1 萬（偏弱）、失業率 4.1%，但 ISM 仍在擴張、GDPNow 偏高 ⇒ 硬軟資料分歧，所以「普通」給最高 | 非農三個月均、失業率、初領失業金 |

⚠️ **看「最近三個月年化」不看「年增率」**：年增率裝的是過去一整年的漲幅，包含早就停下來的那一段。想知道「現在」，要看最近幾個月的速度。

---

## 公式

對 18 種組合（3 油價 × 2 通膨 × 3 就業）的每一種：

```
這個組合的機率 = P(油價) × P(通膨｜油價) × P(就業｜油價)
```

然後把落在同一個情境的組合**加起來**。

**例子**：油價黏著（50%）× 通膨轉熱（55%）× 就業普通（57%）＝ **15.7%**，
規則判定它屬於「連續升息」。

### 為什麼是「條件機率」不是三個數字直接相乘

因為**油價會同時影響另外兩個**——油價飆高會推高通膨、也會壓低成長。
如果假設三者獨立直接相乘，會**低估「壞事一起來」的機率**，把最糟的情境算得太小。

---

## 規則（情境的定義，不是判斷）

```
油價飆破 $115                      → 需求被打壞
就業變差 ＋ 通膨轉熱               → 需求被打壞
就業變差 ＋ 通膨溫和               → 成長驚嚇
通膨轉熱                           → 連續升息
就業很強（通膨溫和）               → 經濟夠強
其餘：油價回落 → 升一次就停；油價黏著 → 連續升息
```

**規則是明文的，可以逐條吵。** 改規則等於改了情境的定義，不是改判斷。

## 結果

| 情境 | 機率 |
|---|---|
| 連續升息，油價黏著 | **44%** |
| 油價再升／需求被打壞 | **24%** |
| 升一次就停，油價回落 | **13%** |
| 經濟夠強，撐得住高利率 | **11%** |
| 通膨降了但經濟也垮了 | **9%** |

---

## 為什麼要繞這一圈

直接說「我覺得停滯性通膨的機率是 24%」，別人只能信或不信，**沒辦法討論**。

但說「我覺得油價飆破 115 的機率是 15%」，你可以拿資料來吵。**而那才是真正在討論。**

> **模型不會讓判斷變客觀。它只是把主觀的地方，從一個藏起來的數字，換成三個攤開來、可以被指正的數字。**

## 該先去查哪一個？（一個我先前算錯的問題）

我原本說「**油價主導一切**」。**那是錯的，錯在測試方法不公平**——我把油價推到「完全確定」（機率 1.0），卻只把核心通膨移動 25 個百分點。標準不同，結論當然偏向油價。

用對等的方式重算（跑 `--info`），問法改成：**「如果我能查清楚其中一個變數，平均而言我的判斷會移動多少？」**

| 變數 | 資訊價值 |
|---|---|
| **就業** | **41.8** |
| 油價 | 35.5 |
| 核心通膨 | 34.0 |

**三個結論：**

1. **最值得先查的其實是就業，不是油價。** 而它剛好是我先前最少著墨的一個。
2. **油價與核心通膨幾乎平手**（35.5 vs 34.0）。以參數本身的不確定性來說，**排序它們沒有意義**。
3. ⚠️ **這個排序有一部分來自模型結構**：通膨與就業都是「條件於油價」的，油價因此帶有額外的間接影響力；分類規則的寫法也會改變誰比較重要。**不要把它當成經濟學結論。**

**為什麼就業會贏**：它是把五格切得最乾淨的那一刀。

- **就業一變差** → 只剩「需求被打壞」63%、「成長驚嚇」37%（其餘三格歸零）
- **就業很強** → 換成「經濟夠強」54%、「連續升息」43%

**兩組的資產結果差很遠**，所以知道就業，等於一次解開對部位影響最大的那個不確定性。
（至於「壞掉」之後是哪一種壞，是核心通膨在決定——不是就業。）

還有一個觀念上的釐清：**油價和核心通膨在這裡不是平行的競爭者。** 油價是外生衝擊，核心通膨有一部分是它的結果。問「哪個重要」有點像問引擎和汽油哪個重要。就業才是相對獨立的第三條腿——它決定聯準會有沒有本錢繼續升，以及升息的代價由誰付。

## 這個模型沒有處理的事

- **時間**：只說六到十二個月內的分布，沒說什麼時候發生。
- **政策失誤**與地緣尾部事件。
- **真實世界不會剛好落在五格裡**，它會是混合的。
- 格子裡的資產判斷是「相對於其他資產」的方向性推論，**不是報酬率預測，也不是任何個別商品的建議**。

## 怎麼自己改

打開 `scenario_model.py` 的 §1，只改那三組數字，存檔重跑：

```bash
python3 scenario_model.py          # 基準
python3 scenario_model.py --info   # 加跑公平的資訊價值分析
python3 scenario_model.py --detail # 列出全部 18 種組合
```

不要動 §2 的規則，除非你真的想改變情境的定義。
