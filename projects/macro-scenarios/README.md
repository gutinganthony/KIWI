# 情境機率模型 — 怎麼算的，為什麼這樣算

> 這份可以直接轉貼給問「那些機率哪來的」的人。
> 程式：`scenario_model.py`（純標準函式庫，不用裝任何套件）
> 資料：`data/monthly.csv`（來源見 `data/SOURCES.md`）

---

## 一句話版本

**兩個問題定義情境，一個東西推動它們，而「會不會一起發生」交給 40 年的歷史資料。**

---

## 先講上一版錯在哪（因為那個錯很常見）

上一版是這樣算的：

```
P(油價, 通膨, 就業) = P(油價) × P(通膨|油價) × P(就業|油價)      ← 錯
```

看起來很像機率課本裡的鏈鎖法則，但少了一個條件。正確的是：

```
P(油價, 通膨, 就業) = P(油價) × P(通膨|油價) × P(就業|油價, 通膨)  ← 對
                                                        ^^^^^^^^^
```

少掉「通膨」這個條件，等於偷偷假設了：**知道油價之後，通膨和就業就互不相干。**

**拿資料一驗，這個假設不成立：**

> 控制油價之後，Δ核心通膨動能 與 Δ失業率 的相關係數是 **−0.41**
> （95% 區間 −0.55 ~ −0.22，1986–2025；分 1990 後、1998 後重算都是 −0.41 上下）

負號的意思是：**通膨和「就業健康」是同方向的**——需求好的時候，通膨升、失業降；需求垮的時候，兩個一起反過來。

所以假設它們不相干，會系統性地錯，而且**錯得有方向**：

| 被算錯的格子 | 方向 | 幅度 |
|---|---|---|
| 停滯性通膨（通膨升＋就業壞） | **高估** | 算成實際的 **1.3 倍** |
| 成長驚嚇（通膨降＋就業壞） | 低估 | −3.1pp |
| 再加速（通膨升＋就業好） | 低估 | −2.6pp |

直覺講：**停滯性通膨之所以罕見，正是因為「通膨燒起來」和「就業垮掉」本來就不太會同時發生。**
假設它們無關，等於把這個保護機制拆掉。

還有三個結構性的問題，一起修掉了：

2. **把三個變數當成平行的輸入。** 其實不平行——見下一節。
3. **情境集混了原因、政策、結果三種東西**（「油價路徑」是原因、「升幾次息」是政策、「成長垮掉」是結果），
   所以會寫出「Brent 破 $115 本身就算停滯性通膨」這種規則，把觸發條件當成結果。
   實際上油價衝到 $125，只讓停滯性通膨從 ~8% 升到 ~11%。
4. **報到小數點後一位**（43.9%）。光抽樣誤差就 ±3pp。

## 這一版的結構：兩個軸，一個推力

**為什麼是通膨和就業當軸？** 從第一性原理走：

```
資產價格 = 未來的現金流 ÷ (1 + 折現率)
              ↑                    ↑
           就業／成長決定        通膨決定
```

**就業管分子，通膨管分母。兩個軸各管一半，互不重複，而且合起來就解釋完了。**

**那油價呢？** 油價不是第三個軸，**它是同時推動那兩個軸的力量**。
把它當成第三個對等的變數，是上一版最根本的設計錯誤。

```
                  ┌──────────┐
      油價 ───────→│  通膨軸  │──┐
       │           └──────────┘  │
       │                         ├──→ 五個情境
       │           ┌──────────┐  │
       └──────────→│  就業軸  │──┘
                   └──────────┘
```

---

## 情境是怎麼切出來的

**通膨軸切三帶、就業軸切兩帶，六格合併成五個情境**（兩個「就業壞掉」的格子合併，因為資產結果一樣）：

|  | 就業撐住（失業率 <4.5%） | 就業壞掉（失業率 ≥4.5%） |
|---|---|---|
| **通膨回到目標**（≤2.5%） | 軟著陸 | 成長驚嚇 |
| **黏著**（2.5–3.5%） | 黏著 | 停滯性通膨 |
| **再加速**（>3.5%） | 再加速 | 停滯性通膨 |

通膨軸切三帶的理由：實測「衝破 3.5%」佔 25% 的機率質量，而它跟「只是黏著」的資產結果不一樣
（前者壓估值倍數，後者主要是政策節奏問題）。切了才有意義，沒切就浪費。

## 公式

用的是統計上的 **Sklar 定理**：任何聯合分布都可以拆成兩塊，而且兩塊可以分開估——

```
聯合分布  =  邊際分布（各自發生的機率）  ×  相依結構（會不會一起發生）
                        ↑                              ↑
                  共識與市場定價                  1986–2025 的實際歷史
                  （這是判斷）                      （這不是判斷）
```

實際算法簡單到一句話：

> 把 1986 年以來每一個月往後看 12 個月，記下「通膨動能變了多少、失業率變了多少」，
> 得到 474 組真實發生過的組合。把它們**按名次排序**，
> 再照我給的邊際機率去切線，數每一格裡有幾組。

```python
# 這就是全部的核心運算
P(通膨在某帶 且 就業在某帶) = 落在那個長方形裡的歷史組合數 ÷ 474
```

**沒有常態分布假設，沒有相關係數參數，沒有模擬。就是數歷史。**

### 為什麼不用高斯 copula（常態）

因為資料不是常態，而且**差很遠**：

| | 偏態 | 超峰度 |
|---|---|---|
| Δ通膨動能 | +1.78 | +7.77 |
| Δ失業率 | +1.70 | +16.90 |

（常態的偏態是 0、超峰度是 0。）

而我們關心的偏偏是**角落那幾格**。實測：高斯 copula 把「通膨升＋就業壞」的歷史基準率算成 **0.9%**，
實際是 **2.1%**。**用錯 copula 的代價，跟用錯獨立假設一樣大。**

## 三個參數，每一個都附出處

| 參數 | 取值 | 依據 | 什麼會讓我改它 |
|---|---|---|---|
| **P(通膨 12 個月後仍 >2.5%)** | 70% | ⚠️ **這是全模型最大的不確定性**，見下 | 核心 CPI／PCE 的 3、6 個月年化 |
| **P(其中衝破 3.5%)** | 30% | 核心 PCE 6 個月年化當下就是 3.46%，剛好壓在門檻上 | 同上 |
| **P(失業率 ≥4.5%)** | 20% | 紐約聯準曲線 13.9%／Goldman 15%／SPF anxious 20%／JPM 20%／WSJ 25%；自算基準率 20% | 非農三個月均、失業率、初領失業金 |
| **油價三態** | 回落 40%／黏著 45%／衝上 $125 15% | Brent 現貨 $107.35；近月曲線逆價差、選擇權 skew 偏高 | Brent 現貨、談判進展 |

### 那個 70% 為什麼是全模型最大的不確定性

**因為兩把尺現在差很多，而且差到 1985 年以來最大：**

- 核心 **CPI** 6 個月年化 **2.57%** → 從這個起點出發，歷史上 12 個月後仍 >2.5% 的比例只有 **34%**（n=189）
- 核心 **PCE** 6 個月年化 **3.46%** → 從這個起點出發，是 **89%**（n=56；放寬到全歷史 n=91 則 93%）

**同一個問題，換一把尺，答案從 34% 跳到 89%。**

聯準會盯的是 PCE，但 SPF 預測的核心 CPI 是 2.7%（仍在門檻之上）。取 70% 是這兩者之間的判斷。
**這一格才是真正該吵的地方**——不是油價。

## 結果

| 情境 | 機率 | 抽樣誤差區間 |
|---|---|---|
| **黏著**（通膨卡在 2.5–3.5%・就業撐住） | **33%** | 29–36% |
| **再加速**（通膨衝破 3.5%・就業撐住） | **25%** | 22–27% |
| **軟著陸**（通膨回到目標・就業撐住） | **23%** | 19–26% |
| **成長驚嚇**（通膨回到目標・就業壞掉） | **10%** | 7–13% |
| **停滯性通膨**（通膨沒回去・就業壞掉） | **10%** | 7–13% |

**三個讀法：**

1. **「就業撐得住」合計 81%。** 這不是樂觀，是外部共識——衰退機率 14–25% 我照抄了。
2. **「通膨沒回到 2.5%」合計 68%。** 這才是主線劇本，不是衰退。
3. **停滯性通膨 10%，不是 24%。** 上一版高估的原因有兩個：獨立假設（1.3 倍）＋把「油價破 115」直接當成停滯性通膨。

### 壓力測試

把兩個邊際同時推到最悲觀（通膨沒回去 85% × 就業壞掉 30%），停滯性通膨也只到 **20%**。
**因為歷史說這兩件壞事不太同時發生**——這個限制不是我設的，是資料設的。

## 油價到底有多重要？（一個我連續講錯兩次的問題）

- 第一次說「**油價主導一切**」→ 錯，測試方法不公平（油價推到機率 1.0，通膨只移 0.25）。
- 第二次說「**先查就業，資訊價值 41.8 > 油價 35.5 > 通膨 34.0**」→ 也不對，因為那個排序建立在「三個變數對等」的錯誤結構上。

**正確答案是：這三個東西根本不對等，排序這件事本身就沒有意義。**

> **通膨和就業是座標軸——它們不是「影響」情境，它們就是情境本身。**
> **油價是推力——它只透過那兩個軸起作用。**

而實測油價的推力**比想像中小得多**：把「油價衝上 $125 會讓 P(就業壞) 增加多少」
從 +4pp 一路調到 +25pp，停滯性通膨只從 10% 動到 12%。

所以要盯的是**兩個軸的讀數**：每月的核心通膨動能（3、6 個月年化，不是年增率）與失業率。
油價是先行指標，不是答案。

---

## 這個模型沒有處理的事

- **時間**：只講 6–12 個月內的分布，沒講什麼時候發生。
- **政策失誤**與地緣尾部事件。
- **真實世界不會剛好落在五格裡**，它會是混合的、而且會在格子之間移動。
- **相依結構假設未來像 1986–2025**。如果供給衝擊變成常態（去全球化、關稅、氣候），
  那個 −0.41 會往 0 移動，停滯性通膨就會變得比模型說的更可能。**這是本模型最大的結構性風險。**
- 格子裡的資產判斷是方向性推論，**不是報酬率預測，也不是任何個別商品的建議**。

## 怎麼自己改

```bash
python3 scenario_model.py               # 基準
python3 scenario_model.py --diagnose    # 獨立假設錯多少、常態性檢定、歷史基準率
python3 scenario_model.py --sensitivity # 兩個邊際在合理範圍內移動
python3 scenario_model.py --bootstrap   # 抽樣誤差區間（較慢）
```

要改判斷，只動 `scenario_model.py` §1 的那幾個數字。
**§2、§3 不要動**——那是情境的定義與資料，改了就不是同一個模型了。

> **模型不會讓判斷變客觀。**
> 它做的是把主觀性關進三個數字，把「兩件事會不會一起發生」交給資料，
> 然後把每個假設攤開，讓別人可以指著其中一條說「這裡錯了」。
