# AI 模型發表事件研究

> 問題：大廠發表新模型（跑分好看），前後有沒有可以把握的股價規律？
> 答案：**有效果，但只有一天、只有 0.7%，而且真正的不對稱在下跌那一側。**

```
python3 fetch.py          # 抓價格（Yahoo chart API；已 vendor 在 data/px/）
python3 agg2.py           # 主結果：逐事件 CAR + 排除財報 + 隨機日期對照
python3 extra.py          # 負面事件、大小版號、供應鏈外溢
python3 final.py          # 逐日拆解 + 可交易性 + 叢聚檢查
```

---

## 方法

- **樣本**：2022-11～2026-09，27 個模型發表／延遲事件（`events.py`，每筆標註是否本 session 查證）。
- **超額報酬**：市場模型。估計期 **[−250, −30] 交易日**，基準 **QQQ**，`AR = r − (α + β·r_QQQ)`。
- **財報污染處理**：⚠️ **這是本研究最關鍵的一步。** 20 天視窗有約三成機率涵蓋一次財報。
  以**成交量**（不是報酬，避免循環論證）在每個日曆季找出最高量那一天當作財報日代理，
  **任何視窗只要涵蓋到財報日，該事件在該視窗被剔除**。
- **對照組**：同股票、同事件數、同樣排除財報，**隨機抽事件日 × 2000 次**。
  這一步在判別「效果」是真的，還是這些股票本來就贏／輸 QQQ。

## 結果

### 1. 財報污染吃掉了大部分「利多出盡」

| 視窗 | 未清理 | **排除財報後** | 隨機對照百分位 |
|---|---|---|---|
| [0,+1] | +0.37% | **+0.74%** | **99% ✅** |
| [+1,+5] | −1.03% | −0.62% | 13% — |
| [+1,+10] | −1.52% | −0.90% | 14% — |
| [+1,+20] | −2.02% | −1.25% | 17% — |

**未清理時看起來有明顯的「利多出盡」（−2%），清理後消失。**
最大的單一污染源是 Llama 3（2024-04-18）：[+1,+20] 是 −18.75%，
但那是 Meta 四月財報的資本支出利空，不是模型的事。

⇒ **唯一通過對照組的是 [0,+1]：+0.74%，勝率 67%，隨機百分位 99%。**

### 2. 效果在哪一天

| 相對日 | 平均 AR | 勝率 | t |
|---|---|---|---|
| −1 | **+0.53%** | **72%** | 1.49 |
| 0 | +0.27% | 62% | 0.79 |
| **+1** | **+0.44%** | 60% | **1.60** |
| +2 起 | 全部轉負或接近零 | | |

**第 −1 天最強**——可能是消息外洩／預期，也可能是不少發表選在前一天收盤後。

### 3. 可交易性（假設你只能在發表當天收盤才買得到）

```
第 0 天收盤買 → 第 +1 天收盤賣
平均 +0.44%   中位 +0.40%   勝率 60%   t=1.60   n=25
標準差 1.37%  ⇒ 單次報酬／風險比 0.32
```

一年約 6 次 ⇒ **毛報酬約 2.6%／年**，還沒扣交易成本與價差。**t=1.60 在傳統標準下不顯著。**

### 4. 大版號 vs 小改版

| | 平均 [0,+1] | 中位 | 勝率 | n |
|---|---|---|---|---|
| **大版號**（ChatGPT／GPT-4／GPT-5／Gemini 1.0／Gemini 3／Llama 2-4…） | **+1.41%** | +1.55% | **80%** | 10 |
| 小改版（.1 .2 .4 .5 等） | +0.26% | +0.43% | 57% | 14 |

⚠️ **這個分類是我在看過逐事件結果之後才寫的，有事後選擇的疑慮**（雖然「整數版號／家族首發」是事前就說得通的規則）。**n=10，需要樣本外驗證才能當真。**

### 5. ⭐ 真正的發現：不對稱

| | [0] | [0,+1] | [+1,+20] |
|---|---|---|---|
| **正面發表**（平均，n=24） | +0.27% | **+0.74%** | −1.25% |
| DeepSeek R1 衝擊（NVDA，2025-01-27） | **−12.04%** | −6.98% | +3.99% |
| Gemini 3.5 Pro 延遲（GOOGL，2026-07-16） | −3.05% | −3.89% | **−9.90%** |

**負面事件的量級是正面的 5–9 倍。**

機制很清楚：**市場已經把「他們會持續推出好模型」定價進去了。**
所以「有推出」的資訊含量接近零，「沒推出／被超越」的資訊含量非常大。
這跟 `projects/pe-model/` 的結論同源——盈餘循環 +41.5% 就是這個賭注的估值形式。

### 6. 供應鏈完全沒有外溢

模型發表日的 [0,+1] 超額報酬：

| 標的 | 平均 | 勝率 | 隨機百分位 |
|---|---|---|---|
| NVDA | +0.01% | 42% | 51% |
| AVGO | +0.21% | 43% | 66% |
| TSM | −0.41% | 48% | 20% |
| AMD | +0.22% | 42% | 64% |
| SMH | −0.22% | 50% | 18% |

**全部跟隨便挑一天沒有差別。** 「大廠發新模型 → 買晶片股」這條沒有統計支持。
（反過來成立：DeepSeek 那種**成本**衝擊才會打到 NVDA，−12% 一天。**動到供應鏈的是成本結構，不是模型能力。**）

## 限制（誠實版）

1. **n=25，樣本小。** [0,+1] 的 t=1.87（全視窗）／1.60（只算 +1 天），**都不到傳統顯著水準**。
   對照組的 99 百分位是比 t 值更強的證據，但兩者都建立在同一批小樣本上。
2. **多重檢定**：測了 7 個視窗 × 多個子樣本。[0,+1] 同時是事前最合理的視窗（消息到、當天到隔天消化完），
   所以不算純挖掘，但仍應打折。
3. **事件叢聚**：4 筆事件在前一事件的 20 天內（Gemini 2.0 Pro 距前 4 日、Gemini 3.8 Live 距前 8 日等），
   重疊視窗會讓顯著性虛高。
4. **6/27 筆日期來自訓練知識、未在本 session 查證**（`events.py` 的 `src="T"`）。
   只用查證過的子樣本重跑，結論方向不變但更弱（[0,+1] t 從 1.87 降到 0.38）。
5. **沒有盤中資料**，無法區分盤前／盤中／盤後發布。這直接影響「第 0 天能不能買到」。
6. **只涵蓋 2022–2026 一個 AI 循環、一個利率環境。** 不能外推到下一個循環。
7. **財報日是用成交量推定的代理**，不是真實財報日曆。方向可靠，個別日期可能差一兩天。
8. **選擇偏誤**：事件清單是我挑的「重要發表」，本身就含事後判斷。
