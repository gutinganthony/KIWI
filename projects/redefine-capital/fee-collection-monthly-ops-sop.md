# 費用收取機制與月度營運 SOP

Redefine Capital · 2026 · 內部作業用。

## 核心觀念（先建立共識）

**費用不是「從投資人帳戶扣款」，而是「從基金淨值扣除」。**投資人沒有個別帳戶，他們持有的是基金股份。機制分兩層：

| 層次 | 做什麼 | 投資人看到什麼 |
|---|---|---|
| **① 計提 Accrue** | 每月算 NAV 時，把管理費列為基金的一筆負債扣除 | 每股 NAV 自然變低——這就是「收到費用」的瞬間，投資人不會看到扣款動作 |
| **② 支付 Pay** | 基金從 IBKR／基金銀行帳戶匯款給 GP 管理公司 | 不影響 NAV（負債已提列），僅為現金移轉 |

**⚠️ 錢的流向必須是：基金帳戶 → GP 管理公司帳戶 →（再由公司分配給 Jake / Vince）。絕對不可從基金直接匯入個人帳戶**——這是治理與 AML 的底線，也是「防捲款」承諾的一部分。

## 一、管理費 2%／年

- **計算基礎**：每月最後一個營業日的基金淨資產（NAV）
- **月費率**：2% ÷ 12 = 0.1667%／月
- **公式**：月管理費 = 月底 NAV × 0.1667%
- **計提頻率**：每月
- **支付頻率**：建議**每季**支付一次（減少電匯次數與費用；累積 3 個月一起付）
- **對誰收**：全體投資人（Class A）。**GP 自己的 Class F 不收管理費、不收績效費**——這是共同投資的誠意，也是標準做法

**範例（AUM US$1,500,000）：**月管理費 = 1,500,000 × 0.1667% ≈ **US$2,500**／月 → 每季支付約 US$7,500 → 年約 US$30,000。

## 二、績效費（Carry）15–20%【費率待定案】

**⚠️ 最重要的陷阱：績效費必須「逐投資人」計算，不可用基金整體計算。**因為每位投資人進場時點與成本不同，高水位線（High Water Mark, HWM）各自獨立。用整體計算會導致後進場者被收取不該付的費用——這是新基金最常犯、也最容易被投資人抓包的錯誤。

- **高水位線 HWM**：只有當該投資人的每股 NAV 創下其個人歷史新高時，才對「超出部分」收費。虧損補回前不收。
- **計算基礎**：（本期每股 NAV − 該投資人 HWM）× 該投資人持股數 × 績效費率
- **計提頻率**：每月計提（反映在 NAV），**年度結算**（12/31）
- **支付時點**：年度結算後，或該投資人贖回時就其部位先行結算
- **結算後**：更新該投資人的 HWM 為新的高點

**為何 Launch 同日同價很聰明：**首輪投資人同日以 US$1,000／股進場，第一年所有 Class A 投資人 HWM 相同，績效費計算最單純。後續新投資人加入後才需啟動系列記帳（series accounting），屆時每個新進系列各自獨立記 HWM。

## 三、每月營運 SOP（月底至次月上旬）

| 時點 | 動作 | 負責 |
|---|---|---|
| 月底最後營業日 | 下載 IBKR 官方月結對帳單，取得總資產與現金部位 | Jake |
| T+1 | Excel 帳本更新：資產 − 應計費用（管理費、績效費）− 其他應付 = 淨資產；÷ 總股數 = 每股 NAV | Jake 編製 |
| T+2~3 | **複核**：另一人獨立核對 IBKR 對帳單、費用計算、每股 NAV；兩人簽核留痕（email 或簽名檔） | Vince 覆核 |
| T+3 | 逐投資人更新：持股數、每股 NAV、部位價值 | Jake |
| T+5 | 月報：NAV＋**IBKR 官方對帳單**＋部位概況／績效／市場觀點 | Jake |
| 每季末 | 累積 3 個月管理費，自基金帳戶匯至 GP 管理公司帳戶；董事會決議留檔 | 兩人 |
| 年末 12/31 | 績效費年度結算、更新各投資人 HWM、支付 | 兩人 |

## 四、現金管理紀律

- **現金緩衝**：IBKR 帳戶保留一定比例現金（建議 3–5%），供贖回與費用支付，避免臨時被迫變現
- **贖回優先於費用**：若當期同時有贖回與費用支付需求，先滿足投資人贖回
- **IBKR 提領限制**：現金僅能提回**基金同名銀行帳戶**，不得提至個人帳戶（這是防捲款承諾的結構性保障，務必在 IBKR 設定時確認）
- **每筆費用支付**：需有董事會決議或雙人簽核紀錄，載明期間、計算基礎、金額

## 五、需要 Jake × Vince 拍板的清單

1. **績效費率**：15% 或 20%？（建議 20% 搭配 HWM，業界標準）
2. **績效費結算頻率**：年度結算（建議）or 季度結算？
3. **管理費支付頻率**：每季（建議，省電匯費）or 每月？
4. **Class F 是否確實免收兩費**：建議是（利益一致的證明）
5. **現金緩衝比例**：建議 3–5%，實際定多少？
6. **誰編製 NAV、誰覆核**：建議 Jake 編、Vince 核，且不可互換以維持獨立性
7. **GP 管理公司**：費用要匯進哪個實體？是否需另設一家管理公司帳戶？（若無，需確認 CO 建議的收費路徑）——**尚未定案，需與 CO 確認**
8. **設立費處理**：GP 墊付、攤提 3 年、或第一年由管理費全額吸收（＝募資須達 ~US$1.5–1.52M）
9. **Excel 帳本格式**：誰建、放哪（建議共用雲端、版本留存）

## 六、數字範例：US$1.5M 基金第一年

| 項目 | 金額 |
|---|---|
| 起始 AUM（Class A 投資人） | US$1,500,000 |
| 管理費（月） | ≈ US$2,500 |
| 管理費（季，實際支付） | ≈ US$7,500 |
| 管理費（年） | ≈ US$30,000 |
| 第一年總成本（設立 US$22,800＋營運 US$7,550） | ≈ US$30,350 |
| **第一年淨缺口** | **≈ −US$350（幾乎打平；Auth rep 若不需要則轉為 +US$2,150）** |
| 第二年起年成本 | ≈ US$7,550 → 每年淨餘 ≈ US$22,450 |

績效費範例：若年報酬 15%，基金淨值成長 US$225,000，以 20% 計績效費 ≈ US$45,000（逐投資人依 HWM 計算後加總）。**這才是 GP 的主要報酬來源——管理費只是覆蓋營運成本。**
